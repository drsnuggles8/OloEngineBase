# GPU readback stats — the channel, and the four ways it lies

Issue #721. How a GPU-driven pass publishes counters to the CPU through `Renderer/Debug/GPUReadbackStats.h`, `GPUReadbackStatsRegistry.h` and `include/GPUReadbackStats.glsl`. Read before adding a counter, instrumenting a pass, or adding a buffer binding. A broken stats channel returns a plausible number instead of an error.

## Rules

1. **Never quote a counter without its frame index.** A counter that stopped updating and one that is genuinely constant are the same bytes. Argue correctness where the number is produced. [Details](gpu-readback-stats-channel-details.md#0-the-governing-property-this-instrument-has-no-wrong-looking-failure)
2. **Add a counter as two lines that agree.** One `X(...)` in `OLO_GPU_STAT_COUNTERS` and one `const uint OLO_STAT_<Name> = <n>u;` at the same index in `include/GPUReadbackStats.glsl`. `GPUReadbackStatsLayoutTest` fails if they differ. The contract is names, not offsets (flat `uint[32]` plus a name registry). Use `oloStatAdd`, `oloStatFlag`, `oloStatOverflow` in GLSL and `GPUReadbackStats::GetLatest()` with `frame.Valid` in C++. [Details](gpu-readback-stats-channel-details.md#1-using-it)
3. **Keep the layout test incapable of passing vacuously.** Every parse asserts non-empty and an independently known count before comparing. If you change how the GLSL declares constants, the test must fail rather than stop checking (#847). [Details](gpu-readback-stats-channel-details.md#2-the-contract-is-names-not-offsets--and-that-was-the-design-decision)
4. **Never add `ClientWaitFence` to `GPUReadbackStats`.** `IsFenceSignaled` is a poll; waiting reintroduces the stall. The ring uses `MemoryResidency::DeviceToHost` buffers read with `ReadBufferSubData`, not persistent-mapped staging. [Details](gpu-readback-stats-channel-details.md#3-what-makes-it-non-stalling-is-the-fence-not-the-buffer)
5. **Skip the capture when the ring is full; retire oldest first.** Keep the newest retired frame instead of blocking; `GetSlotsInFlight()` reports saturation. Walk from `NextSlot` (issue order), not array order, or counters go backwards in time. [Details](gpu-readback-stats-channel-details.md#3-what-makes-it-non-stalling-is-the-fence-not-the-buffer)
6. **Never read a live GPU-written SSBO from the CPU; stage it.** A CPU read makes NVIDIA log 131188 and migrate the buffer VIDEO to HOST (131186), permanently slowing later atomics; throttling the read does not help. Copy to a staging buffer first (`ShaderDebugDraw::StageStatsForReadback`, `VirtualMeshRegistry::ReadFrameCullStats`, `StagedBufferReadback`). Fixed cases: `TerrainGPUQuadtree::PollOverflow`, `FoliageGPUCuller::ReadbackResult` (#1391, guarded by `FoliageCostBaselineTest.ReadingTheCullBackLeavesLaterFramesAsCheap`). [Details](gpu-readback-stats-channel-details.md#3-what-makes-it-non-stalling-is-the-fence-not-the-buffer)
7. **A test must flush to make the fence poll progress.** The engine flushes in SwapBuffers; a test presents nothing, so use `GPUReadbackStatsEvidenceTest::FlushAndWaitForGPU` or the poll spins forever. [Details](gpu-readback-stats-channel-details.md#3-what-makes-it-non-stalling-is-the-fence-not-the-buffer)
8. **Bracket the work, not the graph.** `BeginFrame` must bracket BeginScene..EndScene: it sits in `PrepareFrame` next to `GPUFrustumCuller::BeginFrame` (GPU instance cull dispatches at submission time, before `UploadExecutionState`). `EndFrame` runs in `Renderer3D::EndScene` after `Execute()`, the HZB rebuild and the capture commit. Before hooking a per-frame reset next to an existing one, check your instrumented work runs inside the same bracket. [Details](gpu-readback-stats-channel-details.md#11-the-bug-this-features-own-review-caught-where-the-frame-bracket-goes)
9. **`BeginFrame` uploads the whole block.** That upload zeroes the counters; one never cleared accumulates across the session. An early `EndFrame` copy omits later work and reads smaller; a late `BeginFrame` clears what the frame wrote and reads zero. [Details](gpu-readback-stats-channel-details.md#4-beginframe-and-endframe-bracket-the-graph-and-both-ends-matter)
10. **Never give a reserved slot back in an atomic append.** Reserve with a monotonic `reserveCursor`, bound-check against capacity, record `oloStatOverflow` on refusal, and commit with a separate `instanceCount` incremented only after the write. Zero both words every dispatch. A decrement lets a later writer reuse a slot and corrupts. [Details](gpu-readback-stats-channel-details.md#5-bound-checking-an-atomic-append-reserve-with-one-counter-commit-with-another)
11. **When the count is clamped downstream, neither decrement nor commit.** `VSM_MarkRequiredPages` overshoots `b_RequestCount` on purpose because `VSM_AllocatePages` reads `min(b_RequestCount, VSM_MAX_REQUESTS)`; the honest refusal count is the dropped counter. [Details](gpu-readback-stats-channel-details.md#5-bound-checking-an-atomic-append-reserve-with-one-counter-commit-with-another)
12. **A forced overflow must be real.** `GPUFrustumCuller::SetDebugOutputCapacity(n)` shrinks the bound the shader checks, so the draw really loses instances. A "pretend the flag fired" switch tests only plumbing. [Details](gpu-readback-stats-channel-details.md#6-forcing-an-overflow-must-force-a-real-one)
13. **Read what the pass does with the refused item, and trace the full lifecycle before calling a drop permanent.** `VSM_MarkRequiredPages.comp` drops silently when the ring is full; it self-heals because `VSM_EndFrame` strips `REQUESTS_ALLOCATION` each frame. [Details](gpu-readback-stats-channel-details.md#7-instrumenting-vsm-read-what-the-pass-does-with-the-refused-item)
14. **Do not add a buffer binding without saying so in the issue first.** The namespace `0..83` is full (`SSBO_GPU_STATS = 64` took the last; 57 and 63 are reserved for Vulkan vertex-pull streams). Ride an existing block or renumber a family. [Details](gpu-readback-stats-channel-details.md#8-the-buffer-binding-namespace-is-full)
15. **If `GPUReadbackStatsLayoutTest.NoStatsConsumerAlsoSamplesBinding64` fails, renumber; do not delete it.** It asserts no shader includes both `GPUReadbackStats.glsl` and `DDGICommon.glsl` (cross-namespace reuse collides within one shader). [Details](gpu-readback-stats-channel-details.md#8-the-buffer-binding-namespace-is-full)
16. **Cross-check every counter against something independent of the channel.** Use shader-counted input vs CPU-submitted count, `Drawn` vs `indirect.instanceCount`, the conservation identity `Drawn + Rejected == Input`, and `Latency > 0`. Template: `GPUReadbackStatsEvidenceTest`. [Details](gpu-readback-stats-channel-details.md#9-verifying-a-counter--cross-check-or-dont-claim-it)
17. **Test the lifecycle through the engine, not by hand.** `GPUReadbackStatsFullFrame.RealFrameFeedsTheInstanceCullCounters` renders a real frame via `Scene::OnUpdateRuntime`. Validate a guard by reintroducing the bug and seeing it fail. [Details](gpu-readback-stats-channel-details.md#11-the-bug-this-features-own-review-caught-where-the-frame-bracket-goes)
18. **Measure "does not stall" with paired, interleaved blocks.** Each block measures ON and OFF back to back, use a median within the block, and report the mean of per-block deltas with its standard error. Report "not resolvable above a +/-0.1 ms noise floor", not "free". The `enabled` argument on `olo_gpu_readback_stats` exists for this. [Details](gpu-readback-stats-channel-details.md#10-measuring-it-does-not-stall--the-naive-ab-does-not-work)
19. **When moving a read to an async ring, keep the transient-bit reset on the old synchronous cadence.** Reset unconditionally every frame right after the capture copy is issued (even if the ring skipped the capture); only the read/decide half moves to the fence poll. A write-back may have been cleaning transient state as a side effect (#719, `VirtualMeshRegistry::ProcessResidency`). [Details](gpu-readback-stats-channel-details.md#12-converting-a-synchronous-per-frame-republish-to-an-async-ring-the-reset-does-not-move-with-the-read)
