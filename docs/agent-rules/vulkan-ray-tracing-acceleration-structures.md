# Vulkan ray tracing: the acceleration-structure rules

Issue #978 built the first hardware ray-tracing code in this tree. These are the rules that were not obvious before writing it, in the order they will bite. Read before touching BLAS/TLAS building, GPU Scene instance staging for ray tracing, or ray-query shaders.

## Rules

1. **Build one BLAS per geometry and decide builds in a second pass after accumulating per-geometry demand.** Building per instance writes the same destination twice when two entities share a mesh (invalid usage). [Details](vulkan-ray-tracing-acceleration-structures-details.md#1-a-blas-is-per-geometry-opacity-is-per-instance)
2. **Build every geometry `VK_GEOMETRY_OPAQUE_BIT_KHR` and override per instance** with `VK_GEOMETRY_INSTANCE_FORCE_OPAQUE_BIT_KHR` / `FORCE_NO_OPAQUE_BIT_KHR`. Alpha testing is a material property, not geometry. [Details](vulkan-ray-tracing-acceleration-structures-details.md#1-a-blas-is-per-geometry-opacity-is-per-instance)
3. **Pass the TLAS as a `uvec2` device address and convert with `accelerationStructureEXT(...)` only as a function argument.** No descriptor needed (only `OpCapability RayQueryKHR`); assigning the conversion to a local is a compile error. Carry the ray batch, hit batch and GPU Scene tables as `GL_EXT_buffer_reference` addresses in one UBO. [Details](vulkan-ray-tracing-acceleration-structures-details.md#2-an-acceleration-structure-needs-no-descriptor)
4. **Put anything new on an existing UBO block.** `UBO_RAY_TRACING` (65) took the last free buffer binding in the engine. [Details](vulkan-ray-tracing-acceleration-structures-details.md#2-an-acceleration-structure-needs-no-descriptor)
5. **Record builds into the frame command buffer via `VulkanRendererAPI::BeginAccelerationStructureRecording()`, never `VulkanOneShot`.** One-shot submits ahead of the recording frame and consumes vertex data not yet uploaded; the begin call also closes the lazy dynamic-rendering scope (AS commands are illegal in a render pass). [Details](vulkan-ray-tracing-acceleration-structures-details.md#3-builds-ride-the-frame-command-buffer-never-a-one-shot)
6. **Compact over several frames; never `vkDeviceWaitIdle` and never block on the query.** Build with `ALLOW_COMPACTION`, barrier, `vkCmdWriteAccelerationStructuresPropertiesKHR` in the build's command buffer; poll in a later frame with `VK_QUERY_RESULT_WITH_AVAILABILITY_BIT` and no wait bit; then allocate and record the copy. A blocking read of an unexecuted query never returns. [Details](vulkan-ray-tracing-acceleration-structures-details.md#4-compaction-is-a-multi-frame-handshake-because-idling-is-banned)
7. **Never combine `ALLOW_COMPACTION` and `ALLOW_UPDATE`.** Make it structural: a class that refits never asks to compact. [Details](vulkan-ray-tracing-acceleration-structures-details.md#4-compaction-is-a-multi-frame-handshake-because-idling-is-banned)
8. **Enqueue the acceleration structure handle in `VulkanDeferredReclaim` before its backing `VkBuffer`.** Destruction is in insertion order within a generation; the reverse is a driver use-after-free. [Details](vulkan-ray-tracing-acceleration-structures-details.md#5-retire-the-structure-before-its-buffer)
9. **Range-check `instanceCustomIndex` (24 bits, `FitsInstanceCustomIndex`) and fold the 8-bit `mask` instead of truncating.** A wrapped index resolves to the wrong material on every hit; truncating can hide a high-bit-only effect. [Details](vulkan-ray-tracing-acceleration-structures-details.md#6-two-narrow-fields-truncate-silently)
10. **Copy `GPUSceneTransform` (three row-major `vec4`s) straight into `VkTransformMatrixKHR`'s twelve floats; never via `glm::mat4`.** A transpose gets in. [Details](vulkan-ray-tracing-acceleration-structures-details.md#6-two-narrow-fields-truncate-silently)
11. **AND every liveness test with the record's own `Active` flag, and rebuild the instance list from live records every frame.** `GPUSceneAllocationPolicy::NextGeneration` saturates at `u32` max and leaves the generation unchanged, so a generation-only test accepts a dead record (`GPUScene::GetLive*RecordBySlot` does it right). GPU Scene has no explicit remove; never patch the list. [Details](vulkan-ray-tracing-acceleration-structures-details.md#7-the-stale-record-hole-is-the-generation-counter-saturating)
12. **Report RT capability only when extensions are listed, feature bits are `VK_TRUE`, `vkCreateDevice` accepted them and volk populated the entry points.** Commit the flag after `volkLoadDevice` with entry-point null-checks; keep it Tier-2 optional (never an ADR 0010 gate row), report the reason with the verdict, and keep the lever `OLO_VULKAN_NO_RAY_TRACING=1`. [Details](vulkan-ray-tracing-acceleration-structures-details.md#8-capability-is-four-questions-not-one)
13. **Gate optional-extension usage bits on the enabled capability and clear the verdict in `Shutdown`.** `VK_BUFFER_USAGE_ACCELERATION_STRUCTURE_BUILD_INPUT_READ_ONLY_BIT_KHR` without RT fails every buffer creation (`VUID-VkBufferCreateInfo-None-09499`); check `VulkanDevice::Get()->IsRayQueryEnabled()`. Test with `OLO_VULKAN_NO_RAY_TRACING=1`, since device-backed tests only run where RT exists. For any new capability, grep every flag, stage bit and struct it introduced for what the device must have enabled. [Details](vulkan-ray-tracing-acceleration-structures-details.md#8b-an-optional-extensions-usage-bit-is-invalid-without-that-extension)
14. **Set `VkAccelerationStructureBuildRangeInfoKHR::firstVertex` to 0 for this engine's shared mesh sources; keep `maxVertex = BaseVertex + VertexCount - 1`.** Indices are global; `Submesh::m_BaseVertex` is where a submesh starts. Passing `BaseVertex` applied the offset twice (Sponza's last submesh addressed vertex 195107 of 192492, device loss; non-faulting submeshes traced shifted triangles). Validation layers cannot see it; write a capture comparing `BaseVertex + max(index)` against the vertex count. [Details](vulkan-ray-tracing-acceleration-structures-details.md#8c-firstvertex-is-an-offset-only-for-submesh-local-indices)
15. **Add every new `RHI::Access` write member to `IsWriteAccess` in `RHITypes.h`.** Its `default: return false;` makes a missing write enumerator silently a read, with no barrier or diagnostic. [Details](vulkan-ray-tracing-acceleration-structures-details.md#9-a-new-rhiaccess-write-member-is-silently-a-read)
16. **Map a Vulkan-only access to the closest GL over-approximation in `RenderGraphBarrierPlanner`'s GL flag resolvers, never to `MemoryBarrierFlags::None`.** `None` logs `UnmappedTransition` and drops the barrier record, so the Vulkan lowering is never reached. [Details](vulkan-ray-tracing-acceleration-structures-details.md#9-a-new-rhiaccess-write-member-is-silently-a-read)
17. **Allocate AS storage with `vmaCreateBufferWithAlignment` at 256-byte alignment, and record `accelerationStructureHostCommands` / `accelerationStructureIndirectBuild` as false on the dev GPU without gating on them.** Scratch needs `minAccelerationStructureScratchOffsetAlignment` (128 on RTX 4090, driver 610.88, SDK 1.4.357); plain `vmaCreateBuffer` can suballocate 16-aligned (VUID-…-offset-03734). Limits: `maxInstanceCount` = `maxGeometryCount` = 16777215, `maxPrimitiveCount` = 536870911. [Details](vulkan-ray-tracing-acceleration-structures-details.md#10-measured-on-the-development-gpu-rtx-4090-driver-61088-sdk-14357)
18. **Classify an animated instance as `Deformed` only when its geometry also carries `GPUSceneGeometryFlagDeformed`; otherwise refuse it as `Unsupported`.** `RayTracingScene::Classify` does it and counts `ResidentCounters::AnimatedInstancesRefused`; without the check, skinned entities (no longer filtered upstream since #1228) got a build-once T-pose BLAS. Test the property you depend on at the point you depend on it, not an upstream filter. See deformed-surfaces-in-acceleration-structures.md. [Details](vulkan-ray-tracing-acceleration-structures-details.md#what-is-deliberately-not-solved-here)
19. **Supply the alpha helper's texel fetch as a caller-defined macro through the descriptor heap (ADR 0011 amendment (95)).** Consumers: `HybridRayTracingAlpha.glsl`, `RayTracedSurfaceHit.glsl`, `ReSTIRDISceneAccess.glsl`; `compute/RayTracingProbe.comp` tests the policy against alpha = 1. Virtual-geometry parts trace a fixed proxy mesh and classify `Static` (ADR 0023). [Details](vulkan-ray-tracing-acceleration-structures-details.md#what-is-deliberately-not-solved-here)
