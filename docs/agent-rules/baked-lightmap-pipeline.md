# Baked lightmaps (#439): the units ledger, the seam-split staleness trap, and adding a vertex channel without touching `Vertex`

Rules for the baked-GI path: the offline CPU lightmap bake (xatlas UV2 unwrap plus `PathTracer::EstimateIrradiance` per texel), the path-traced SH probe bake, and the runtime sampling and staleness machinery. Read before touching `Renderer/Baking/**`, `Scene/SceneLightmap.*`, `include/LightmapSampling.glsl`, the lightmap branch of `PBR_MultiLight.glsl`, or `LightProbeBaker`'s path-traced mode.

## Rules

1. **Compute the bake staleness key after `Prepare()` (post-unwrap counts), and keep `SceneLightmapRuntime::Resolve` able to re-derive that state.** `Resolve` re-unwraps a lightmap-static mesh with no UV2 stream before the key check. A key over pre-derivation state validates confidently while the derived data is absent. Keep unwrap parameters out of settings: use the shared `kLightmapUnwrap*` constants (`LightmapUnwrap.h`) in `Prepare()` and the resolve; do not re-add `UnwrapResolution`/`UnwrapPadding` to `LightmapBakeSettings`. Hash what the bake consumes (raw `TransformComponent::Translation`, nothing for `!(intensity > 0)` lights; `SceneLightmapStalenessTest`). Vendor CMake pins `XA_MULTITHREADED=0` for a deterministic unwrap. [Details](baked-lightmap-pipeline-details.md#2-the-unwrap-seam-splits-vertices--so-the-staleness-key-must-be-computed-after-it-and-the-resolve-must-be-able-to-re-derive-it)
2. **Add a per-vertex channel as a parallel stream on `MeshSource` (`m_LightmapUVs`), not a member of `Vertex`.** Widening `Vertex` breaks the 32-byte static_asserts, ~38 shaders' `gl_VertexIndex * 8` pull branch and the `.omesh` stride. Give the stream its own `meshopt_remapVertexBuffer` block in `MeshOptimization::OptimizeMesh`, or its data silently belongs to other vertices. Attribute locations follow `AddVertexBuffer` order: the lightmap stream is added only when `!HasSkeleton()`, pinning `a_TexCoord2` at location 3. Back an optional stream consumed by a shared program with `VertexArray::AddConstantVertexBuffer` on meshes lacking it (mixed layouts make NVIDIA recompile, GL debug id 131218); Vulkan implements it as a deliberate no-op. [Details](baked-lightmap-pipeline-details.md#1-a-new-per-vertex-channel-does-not-have-to-widen-the-vertex-struct--and-here-it-must-not)
3. **Respect the units ledger.** DDGI atlas stores full irradiance E; the lightmap stores indirect-only E; the SH volume stores raw band-limited radiance (`ProjectToSH`, no cosine convolution) and the sampler reads it with `evaluateSHCosineIrradiance`. The ambient ladder converts every E to E/pi once (`oloNormalizedIrradiance`), and lightmap pixels must replace probe/IBL diffuse, never add to it. See [lighting-signal-contract.md](lighting-signal-contract.md). [Details](baked-lightmap-pipeline-details.md#3-the-units-ledger--who-stores-e-who-does-not)
4. **Derive every texel and probe seed from its address, never from the worker.** `MakePixelSeed(x, y, bakeSeed)` for texels, grid index for probes, packing sorted by (region size, UUID). Bakes must memcmp-equal at any thread count. [Details](baked-lightmap-pipeline-details.md#4-determinism-is-what-makes-the-bake-testable--and-it-is-a-property-of-the-seeds-not-the-scheduler)
5. **Branch the shader on lightmap coverage (`sampleLightmapIrradiance(...).a`), never on colour.** Alpha separates validly baked black (keep its darkness) from never baked (fall through to probes/IBL); un-premultiply `.rgb` by the sampled alpha. Never put an `OLO_BINDLESS` token in `LightmapSampling.glsl` (it drags every includer onto the raw-GLSL route, glsl-shaders.md section 5e); publish the atlas through `HeapBinding::PublishTextureOffsetAndBind`. [Details](baked-lightmap-pipeline-details.md#5-reused-patterns-that-are-contracts-not-conveniences)
6. **Treat the lightmap atlas as a `sampler2DArray` at TEX 16, one layer per page.** `Renderer3D` owns a 1x1x1 RGBA16F placeholder array (not `s_Data.WhiteTexture`). `Texture2DArray::SetLayerData` needs native data per format, so pack f32 texels with `glm::packHalf1x16`. [Details](baked-lightmap-pipeline-details.md#the-gpu-side)
7. **Carry per-draw lightmap regions on the Color/Custom pattern end to end.** `DrawMeshCommand` field, then a vec4 FrameDataBuffer stream entry per source in `CommandBucket::BatchCommands`, then `InstanceData` in both dispatch paths; a value skipping the stream is shared once batching merges entities. Keep `Resolve()` throttled and memoized (`kResolveRecheckIntervalFrames`; a failed unwrap is memoized until `Invalidate()`); call `Invalidate()` on bake completion and `.olmap` hot-reload. After a change spanning targets, remember which target the verifying build compiled: `Ref<T>` propagates const through `operator->`, and `input.Mesh->Build()` on a const ref failed only in the unbuilt target (twice). [Details](baked-lightmap-pipeline-details.md#5-reused-patterns-that-are-contracts-not-conveniences)
8. **Write RT5 from every G-Buffer shader: `o_GBufferBakedGI = vec4(0.0);`** An unassigned MRT output is undefined, and RT5 `.a` is a coverage flag. `GBufferBakedGIContractTest` scans shader sources for it. [Details](baked-lightmap-pipeline-details.md#the-contract-this-added-and-the-three-ways-it-fails-silently)
9. **Spell out every `DecalRenderPass` draw-buffer entry; the arrays are sized `GBuffer::Count`.** A short initializer zero-fills the tail, which means "writes attachment 0". `fullDrawBufs` (the restore set) must name RT5. Clear RT5 to `vec4(0)` explicitly in `SceneRenderPass`, not via `ClearAllAttachments`. [Details](baked-lightmap-pipeline-details.md#the-contract-this-added-and-the-three-ways-it-fails-silently)
10. **Store raw baked irradiance E (rgb) plus coverage (a) in the sixth G-Buffer target (RGBA16F), fetched in the G-Buffer pass; never the atlas UV or the shaded ambient.** MSAA resolve averages UVs into wrong addresses, and decals rewrite albedo afterwards. The target is unconditional (it keys transient-pool aliasing). Test with `LightmapVisualEvidenceTest.BakedBleedSurvivesTheDeferredPath`. [Details](baked-lightmap-pipeline-details.md#7-the-deferred-path-carries-irradiance-not-the-atlas-uv-865)
11. **Keep the Vulkan UV2 pull behind a vertex-stage `LightmapScaleOffset.x > 0.0` guard.** An unguarded pull of an unbaked mesh reads past the 64 KiB frame-arena null block and device-losts. Lightmap pull rides `SSBO_BONE_PULL` (63); a draw needing bones and UV2 would break that (ADR 0011 amendment 89). [Details](baked-lightmap-pipeline-details.md#6-deliberately-deferred-so-nobody-re-derives-the-gap-as-a-bug)
12. **Change receiver region identity only through `Scene/SceneLightmapGather.h`.** One shared gather feeds the bake, reference world, re-unwrap and key; rules: [lightmap-receiver-identity.md](lightmap-receiver-identity.md). [Details](baked-lightmap-pipeline-details.md#6-deliberately-deferred-so-nobody-re-derives-the-gap-as-a-bug)
13. **Keep the reference tracer's sampling model its own (ADR 0022).** Textures and sky enter via `ReferenceSceneBuildOptions::MaterialMapProvider` / `::EnvironmentCubemap`; parity fixtures pass neither, and `LightmapSkyAndTextureBake.AProviderThatSuppliesNoMapsChangesNothingBitForBit` asserts it with `memcmp`. Validate HDRI bakes with furnace, `E = pi * L` and quadrature checks. [Details](baked-lightmap-pipeline-details.md#6-deliberately-deferred-so-nobody-re-derives-the-gap-as-a-bug)
14. **Do not reason about over-budget scenes as graceful degradation: overflow entities are dropped.** Regions pack largest-first into a buddy quadtree, so the halving loop is unreachable; paging (page first, degrade second) is the remedy. `LightmapAtlasPagingTest.MeasureSinglePageOverloadDropsEntitiesRatherThanDegrading` pins the baseline with a page budget of 1. [Details](baked-lightmap-pipeline-details.md#the-measurement-came-back-different-from-the-issues-premise--read-this-before-trusting-the-old-description)
15. **Fold the page into the texel seed as `MakePixelSeed(x, y + page * atlasSize, seed)`.** Page 0 seeds stay unchanged (`LightmapBakeParityTest`). [Details](baked-lightmap-pipeline-details.md#ordering-page-first-degrade-second)
16. **Encode the page in the integer part of `.z` of `InstanceData::LightmapScaleOffset`: `vec4(scaleX, scaleY, offsetX + page, offsetY)`.** Compose it only in `SceneLightmapRuntime::Resolve`, decode it only in `sampleLightmapIrradiance`; never touch the scale lane, since every "no lightmap" gate reads `.x`. `LightmapPageEncodingTest` asserts it exactly. [Details](baked-lightmap-pipeline-details.md#the-page-index-rides-in-the-integer-part-of-z)
17. **Change `Renderer/LightmapPageEncoding.h` and `decodeLightmapPage` / `decodeLightmapOffset` together.** Cover the GLSL half with a text-scan test (`LightmapPageEncodingTest.ShaderCarriesTheMatchingPageDecode`), negative-checked by breaking the shader. [Details](baked-lightmap-pipeline-details.md#the-page-index-rides-in-the-integer-part-of-z)
18. **Keep the page budget a constant, not a setting.** `kLightmapAtlasMemoryBudgetBytes` (64 MiB) via `LightmapPageBudget(atlasSize)`, clamped to `[1, kMaxLightmapPages]`; the effective ceiling is `max(one page, floor(budget / pageBytes)) * pageBytes`. If it ever becomes authorable it MUST join `SceneLightmapRuntime::ComputeBakeKey`. `LightmapBakeSettings::MaxAtlasPages` may only ask for fewer. [Details](baked-lightmap-pipeline-details.md#the-budget-policy-a-vram-constant-deliberately-not-a-setting)
19. **Reject out-of-range pages in two places.** `LightmapAsset::Validate()` rejects `entry.Page >= m_PageCount`, and `Resolve()` bounds-checks against `asset->GetPageCount()` and `kMaxLightmapPages`, skipping and warning. [Details](baked-lightmap-pipeline-details.md#what-replaced-the-page--0-rejection)
