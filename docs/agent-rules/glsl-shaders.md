# GLSL Shader Authoring Rules

Applies to: `**/*.glsl`

The engine compiles all GLSL through shaderc to SPIR-V, which is stricter than plain OpenGL GLSL. Follow these or compilation (or a Vulkan-only runtime step) fails.

## Rules

1. **Put every non-opaque uniform in a named UBO block** (`layout(std140, binding = N) uniform Name { ... };`). Samplers and images may be standalone; no `gl_FragColor`, give every varying and output an explicit `layout(location = N)`, use explicit constructors (`vec3(0.0)`, not `vec3(0)`). [Details](glsl-shaders-details.md#1-spir-v-constraints)
2. **Never call `.length()` on a storage buffer.** It becomes `OpArrayLength`, which access-violates inside the Vulkan driver at pipeline creation; pass a count in a UBO or bound by a generation. Pinned by `VulkanMeshPipelineFamily.EveryShippedMeshShaderProducesAPipeline`. [Details](glsl-shaders-details.md#6b-never-call-length-on-a-storage-buffer)
3. **Declare a UBO used in two stages of one file identically, member names included** (keep `u_Model` in the fragment stage); link fails otherwise and `glslc` per-stage cannot show it. [Details](glsl-shaders-details.md#1-spir-v-constraints)
4. **Give padding a block-specific name** (`_pbrMaterialPad0`, not `_padding0`): nameless blocks share the global namespace and a duplicate is a Vulkan-only SPIR-V error. [Details](glsl-shaders-details.md#std140-padding-rules)
5. **Take `abs()` of `projection[1][1]` before using it as a scale;** it is negative on Vulkan and fails silently. [Details](glsl-shaders-details.md#1-spir-v-constraints)
6. **Write all five forward MRT outputs** (`o_Color`, `o_EntityID`, `o_ViewNormal`, `o_Velocity`, `o_SkinDiffuse`). A shader in the scene pass that does not shade skin writes `o_SkinDiffuse = vec4(0.0);`, first in `main()` if it returns early; omitting it puts garbage on screen. Only `Renderer2D_*` are exempt. [Details](glsl-shaders-details.md#4-mrt-output-forward-pass)
7. **Run `python scripts/check_shader_extension_floor.py` after adding any `#extension`.** The floor is Vulkan SDK 1.4.357.0 / shaderc `v2026.3`; raising it moves four literals together (`setup-vulkan` `version`, `shaderc-version`, `spirv-cross-version`, `kMinimumVulkanSdk`/`kMinimumShadercTag` in `ShaderToolchainFloor.h`). Never hide an extension behind `#ifdef` for an old toolchain. [Details](glsl-shaders-details.md#1a-a-new-extension-must-be-within-the-toolchain-floor--check-it-before-you-commit)
8. **Match `ShaderBindingLayout.h` exactly for UBO/texture/SSBO bindings and the C++ struct layout.** `vec3` takes 16 bytes, scalars after it start a new 16-byte group, struct size is a multiple of 16. SSBO slots stay below `SSBO_BINDING_LIMIT` (80). [Details](glsl-shaders-details.md#3-ubo-blocks-std140)
9. **Name placeholder members of a shared UBO with a leading underscore;** `CrossShaderUBOMemberOffsetsAgree` only flags two non-underscore names at one offset. Members use `u_`, blocks PascalCase. [Details](glsl-shaders-details.md#naming)
10. **Separate stages with `#type` markers** (`vertex`, `fragment`, `tess_control`, `tess_evaluation`; `task`/`mesh` are Vulkan-only and loaded only behind `RenderCommand::SupportsMeshShaders()`). [Details](glsl-shaders-details.md#2-file-structure)
11. **Write velocity as the UV-space delta `(ndcCurr - ndcPrev) * 0.5` with TAA jitter removed** (`oloVelocityFromNdc`, `oloUnjitterClip`). Consumers depth-gate background pixels and use a `hasVelocity` flag. [Details](glsl-shaders-details.md#4a-motion-vectors--velocity-buffer-g-buffer-rt3--forward-attachment-3)
12. **Assign samplers with `layout(binding = N)`, never `glUniform1i`;** consult `ShaderBindingLayout.h` before using slots 13-31. [Details](glsl-shaders-details.md#5-texture-bindings)
13. **Convert a shader to heap-bindless by wrapping declarations only** (`#ifdef OLO_BINDLESS` with `OLO_HEAP_TEX_2D(<TEX_* slot>)`, else `layout(binding = N)`), paired with `BindTextureOrHeapOffset` + `FlushHeapOffsets()` in C++ and a deliberate lifetime. Never write `#extension GL_ARB_bindless_texture` yourself. [Details](glsl-shaders-details.md#5a-the-heap-bindless-alternative--opt-in-and-ssaoglsl-is-the-worked-example)
14. **Storage images use `OLO_HEAP_IMAGE(format, qualifier, type, name, unit)` declared inside the using function;** `readonly` is not passable (use `OLO_HEAP_IMAGE_RW` on the bindless arm), the number is an image unit, bind the shader before the image, flush per ping-pong iteration, and `grep -rn "<name>" assets/shaders/include/` (transitively) before converting. [Details](glsl-shaders-details.md#5b-storage-images-through-the-heap--three-things-differ-and-each-is-forced)
15. **Convert a bindless shader's C++ bind and its declaration in the same change.** A partly converted shader makes every unconverted `layout(binding)` sampler read black; `NoBindlessRouteShaderKeepsASlotBasedSamplerDeclaration` checks it. [Details](glsl-shaders-details.md#5c-once-a-shader-is-partly-converted-the-two-sides-can-no-longer-move-separately)
16. **Do not convert a shader that names `gl_BaseInstance` or `gl_BaseVertex`** (`grep -nE "gl_BaseInstance|gl_BaseVertex" <shader>`); only `gl_InstanceIndex` and `gl_VertexIndex` are rewritten. [Details](glsl-shaders-details.md#5c-bis-vulkan-only-builtins--two-are-bridged-two-are-still-blockers)
17. **Pick the heap sampler macro that matches the type** (`OLO_HEAP_TEX_2D_INT` for `isampler2D`); do not convert G-Buffer shader images. [Details](glsl-shaders-details.md#5d-a-heap-handle-carries-no-type--pick-the-matching-sampler-macro)
18. **A sampler- or image-declaring shader is converted or listed in `kSlotBasedByDesign` with a reason** (`EveryShaderIsOnTheRouteOrExplicitlyExcluded`). Check who binds the slot (`grep -nF -- "->Bind(" <file>`); `RHI::SamplerDesc{}` inherits the texture's state. [Details](glsl-shaders-details.md#5e-every-sampler-declaring-shader-is-converted-or-a-recorded-decision)
19. **For Vulkan, do not rewrite buffer or sampler declarations;** a vertex stage consuming attributes needs an `#ifdef OLO_VULKAN` vertex-pulling branch reading binding 57 (`OloVertexPull`) by `gl_VertexIndex`. [Details](glsl-shaders-details.md#5f-the-vulkan-backend-691-your-declarations-survive-only-a-vertex-stage-changes)
20. **Do not write a `*_Instanced` shader variant;** instancing reads `InstanceData[]` at binding 15, so a wrong instanced shader is fixed in C++ shader selection. [Details](glsl-shaders-details.md#6a-instancing-is-shader-transparent--dont-write-a-separate-_instanced-variant)
21. **Keep depth-prepass vertex math expression-for-expression identical to the standard mesh programs,** all with `invariant gl_Position;`; change both together. MASK variants keep the exact alpha test. [Details](glsl-shaders-details.md#7a-depth-prepass-position-invariance)
22. **Every shader declaring `invariant gl_Position` must be on the same compile route;** one with no samplers adds `#define OLO_BINDLESS_ROUTE_PARITY 1`. [Details](glsl-shaders-details.md#7a-bis-invariant-does-not-survive-a-change-of-compile-route)
23. **Budget constant arrays by emitted assignment count;** pack big tables (two halfs per uint) and declare dynamically-indexed tables global, not `const`. A shared-include change is proven only by the largest including shader. A link failure shows as `Shader linking failed for` in `OloEngine.log`. [Details](glsl-shaders-details.md#8a-a-large-const-array-in-a-shared-include-is-a-link-time-driver-bomb-and-glslc-cannot-see-it)
24. **Use constant indices, not a data-dependent loop, over indexed arrays** (Mesa AMD compile blowup). [Details](glsl-shaders-details.md#8b-a-data-dependent-loop-over-indexed-arrays-is-a-compile-time-bomb-on-mesas-amd-path)
25. **Do not build a projection basis from the vector you project, then measure against it again** (GTAO lesson); use the camera view vector `normalize(-pixCenterPos)` throughout. [Details](glsl-shaders-details.md#8-common-mistakes)
26. **Run display-range filters (CAS) after `ToneMapPass`, not in HDR-linear;** a stage inserted into the post chain must be added above its predecessor in every downstream `ReadFirstValidVersionedInputForPass` list. TAA's sharpen stays in HDR, clamped to the 3x3 range and out of `TAAHistory`. [Details](glsl-shaders-details.md#9-display-range-vs-hdr-linear-post-process-ordering)
27. **When porting D3D/HLSL screen-space code, re-derive every Y convention for GL's bottom-left origin** and verify at a grazing angle; probe inputs with `olo_render_probe_pixel`. [Details](glsl-shaders-details.md#10-porting-d3dhlsl-reference-code-audit-every-screen-space-y-convention)
28. **Never use a locality-preserving index (Hilbert LUT) as noise;** map it through R2 and test the noise as a field (neighbour, range, frame correlation). [Details](glsl-shaders-details.md#11-quasi-random-sampling-a-locality-preserving-index-is-not-noise)
29. **Use `#pragma optimize(off)` for a stage only with measured compiler evidence,** then revalidate speed and numerics. [Details](glsl-shaders-details.md#per-stage-spir-v-optimization-opt-out)
30. **Include shared headers with `#include "include/..."`** (cycle-detected; headers in `OloEditor/assets/shaders/include/`). [Details](glsl-shaders-details.md#7-include-system)
