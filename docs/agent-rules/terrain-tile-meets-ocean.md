# A terrain tile meeting an ocean — the border is the bug, and it is not in the frame

Applies to: `OloEngine/src/OloEngine/Terrain/TerrainGenerator.{h,cpp}`, any scene that puts a `TerrainComponent` and a `WaterComponent` in the same world. From issues #880 and #942 (*Drift*'s procedural island field).

## Rules

1. **Fix a tile-border wall with a radial term (`TerrainHeightShaping::IslandFalloff`), never by tuning uniform knobs.** Ridge blend, domain warp, terracing, `HeightExponent` and erosion are all uniform over the tile; land fraction tracks border-above-water to within a point at every setting (exponent 3.0, sea 0.800 gave 1.4% land and 1.1% border), so no parameter set yields an island with a clean edge. [Details](terrain-tile-meets-ocean-details.md#1-every-knob-was-uniform-so-none-of-them-could-fix-a-radial-problem)
2. **Measure the border before designing: transcribe `GenerateHeightField` into a standalone probe.** It depends only on `SimplexNoise3D`, `glm` and the standard library. Report land fraction, border-above-cut fraction, highest border texel and a 44x44 ASCII coastline map. Run `clang-cl` from PowerShell; in Git Bash MSYS path conversion mangles `/O2` into `C:\Program Files\Git\O2.obj`. [Details](terrain-tile-meets-ocean-details.md#2-measure-at-the-border-it-takes-three-seconds-and-it-decides-the-design)
3. **End the falloff ramp at `0.5 - 0.5/resolution`, not at `0.5`.** Every border texel then lands on exactly zero (corners included) and the test is an equality: `EXPECT_FLOAT_EQ(MaxBorderHeight(heights, resolution), 0.0f)`. `TerrainGeneratorTest.IslandFalloffDrivesEveryBorderTexelToZero` sweeps `{32, 64, 127, 128}` and asserts the peak survives. [Details](terrain-tile-meets-ocean-details.md#3-the-ramp-must-end-on-the-outermost-sample-not-on-the-tiles-geometric-edge)
4. **Apply the mask before the exponent and the terrace.** Both map 0 to 0 (`Terrace(0) == 0` holds because the smoothstep argument clamps), so the border guarantee survives and they shape the island profile rather than the ramp. A shaping pass that does not map 0 to 0 must come before the mask or force the mask after it. [Details](terrain-tile-meets-ocean-details.md#4-apply-the-mask-before-the-exponent-and-the-terrace-not-after)
5. **Re-apply the mask factor after `ApplyErosion`, only on texels where the mask is zero.** Droplets that die on the border deposit sediment there. Pin it with `IslandFalloffSurvivesTheErosionPostPass`, which asserts erosion actually changed the field. A mid-pipeline guarantee holds only until the next pass that ignores it. [Details](terrain-tile-meets-ocean-details.md#4-apply-the-mask-before-the-exponent-and-the-terrace-not-after)
6. **Put the seafloor plane below the tile base.** With the mask on, the border sits exactly at the entity's `y`; a seafloor above it slices the island's flank into a flat lid. Drift: seafloor `y = -26`, island base `y = -24`. [Details](terrain-tile-meets-ocean-details.md#5-the-seafloor-plane-must-sit-below-the-tile-base--and-this-bites-after-the-fix)
7. **When resizing a `WaterComponent`, restate metres per quad, not the grid count.** `WorldSizeX/Z` and `GridResolutionX/Z` are independent; 1.6 km at 384 would be 4.2 m per quad, and 640 restores 2.5 m. Same for `TerrainComponent`'s `ProceduralResolution` vs `WorldSizeX` and the splatmap against both. [Details](terrain-tile-meets-ocean-details.md#6-widening-the-sea-silently-coarsens-it--the-grid-is-a-count-the-quad-is-the-knob)
8. **Set `TessellationEnabled` (and foliage `UseImpostor`) in every shipped scene that should use the feature.** A flag set only in the test written with the feature means test coverage and no product coverage. Check with `grep -rn "TessellationEnabled: true" OloEditor/SandboxProject/Assets/Scenes/` (see terrain-gpu-lod-quadtree.md §1). [Details](terrain-tile-meets-ocean-details.md#7-tessellationenabled-is-still-a-flag-scenes-forget)
9. **Expect the falloff ramp to be an outer flank of about `atan(HeightScale / ((0.5 - IslandFalloffRadius) * WorldSizeX))`, and keep slope-keyed layer rules clear of it.** Ridgeback: `atan(110 / 84)` = 53 deg; Drift islands land at 45-55 deg. A rock rule opening at `MinSlopeDeg: 48` claimed 77-93% of the surface and `EvaluateLayerWeights` normalization starved the altitude-banded layers. [Details](terrain-tile-meets-ocean-details.md#8-the-mask-you-added-to-make-a-shoreline-is-also-a-50-deg-slope-and-anything-keyed-on-slope-now-sees-it)
10. **Pin layer coverage, not weight variation.** Weights varied fine while one layer took the surface and others got ~0%. `DriftIslandSplatCoverageTest` reads the shipped scene so scene and guard cannot drift. When every stage is correct (gate, deserialization, splatmap, sampling), suspect the rule bands. [Details](terrain-tile-meets-ocean-details.md#8-the-mask-you-added-to-make-a-shoreline-is-also-a-50-deg-slope-and-anything-keyed-on-slope-now-sees-it)
11. **Anchor altitude bands on the measured `[min, max]` of the shaped field, not `[0, 1]`.** The mask and `HeightExponent > 1` keep the field below 1.0 (Mesa peaks at 0.800), so summit bands at 0.844-0.856 never matched. `GenerateHeightmap` logs the range as `height=[...]`. [Details](terrain-tile-meets-ocean-details.md#the-second-half-bands-anchored-on-a-range-the-field-never-reaches)
12. **Give an island one shared cliff threshold theta: altitude bands stop at theta, the bare-rock rule starts at theta, same `SlopeBlend`.** Pick theta from the island's own steepest ~25-30% slopes; unrelated slope numbers leave gaps (falling to layer 0) and overlaps. [Details](terrain-tile-meets-ocean-details.md#authoring-rule-that-falls-out-of-both)
13. **Keep band edges off the flat plateau values of terraced fields and model offline in float32.** With `ShapingTerraceSteps` an edge on a plateau value is decided by the last bit; the f64 model and the engine's f32 `SmoothBand` chose opposite layers across 36% of Mesa. [Details](terrain-tile-meets-ocean-details.md#a-float-trap-on-terraced-fields)
14. **Separate adjacent materials by hue, not brightness, and guard with plain RGB distance (threshold 0.18).** The scene's warm sun (3.2), exponential fog (0.0009) and ACES compress luminance; brightness-only pairs (Rock/Heath 0.135, Palm scrub/Green cap 0.075) read as one mass. The shipped palette's worst pair is 0.223. [Details](terrain-tile-meets-ocean-details.md#coverage-is-necessary-not-sufficient--the-palette-has-to-survive-the-air)
