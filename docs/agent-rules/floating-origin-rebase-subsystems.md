# Floating-origin rebase — the four subsystems that hold world-space state outside the ECS (issue #613)

`Scene::RebaseOrigin(shift)` (issue #429) shifts every root `TransformComponent`, all Jolt rigid bodies, static terrain, character controllers and Box2D bodies when the camera drifts past `WorldOriginSettings::RebaseThreshold`. Anything holding absolute world-space state outside that set silently desyncs (no crash, geometry drifts from physics/nav/render). Read before touching a world-space cache.

## Rules

1. **Keep a rebase a pure uniform translation:** every position becomes `old + shift`; velocities, rotations and constraint errors are unchanged. [Details](floating-origin-rebase-subsystems-details.md#floating-origin-rebase--the-four-subsystems-that-hold-world-space-state-outside-the-ecs-issue-613)
2. **Shift a cloth soft body by its centre of mass,** with the same `bodyInterface.SetPosition(id, GetPosition(id) + joltDelta, DontActivate)` as rigid bodies, looping over `JoltScene::m_Cloths` in `ShiftOrigin` (Jolt has no `PhysicsSystem::ShiftOrigin`). Do not add `delta` to `SoftBodyMotionProperties::GetVertices()`: they are COM-relative. [Details](floating-origin-rebase-subsystems-details.md#1-cloth-soft-bodies--shift-the-body-com-and-the-cpu-cache-too)
3. **Shift the cloth CPU cache too:** `Scene::m_ClothRuntime[*].m_Positions` is absolute-world, so `RebaseOrigin` adds `delta` (step 4) or one frame shows a cloth pop. `m_Normals` are directions and stay. [Details](floating-origin-rebase-subsystems-details.md#1-cloth-soft-bodies--shift-the-body-com-and-the-cpu-cache-too)
4. **Shift world-anchored single-body joints with `constraint->NotifyShapeChanged(JPH::Body::sFixedToWorld.GetID(), -joltDelta)`** (Fixed/Point/Distance/Hinge/Slider/Cone/SwingTwist/SixDOF/Path). The world body's COM transform is identity, so `-delta` moves the anchor by `+delta`; constraint error, motors and warm-start impulses survive. Do not destroy and rebuild these (it re-pins a compliant joint to the drifted body and loses the tether). [Details](floating-origin-rebase-subsystems-details.md#2-world-anchored-constraints--notifyshapechanged-for-the-exact-shift-rebuild-only-the-pulley)
5. **Rebuild a pulley instead.** Its `mFixedPoint1/2` have no runtime setter and `NotifyShapeChanged` moves only body-attach points: shift `PhysicsJoint3DComponent::m_PulleyFixedPointA/B` by `delta`, then `DestroyConstraint` + `CreateConstraint`, after the body shift in `ShiftOrigin` so it reads shifted transforms. Vehicles and two-real-body joints need nothing. `HasWorldAnchoredConstraints` is diagnostics only, no longer gating the rebase. [Details](floating-origin-rebase-subsystems-details.md#2-world-anchored-constraints--notifyshapechanged-for-the-exact-shift-rebuild-only-the-pulley)
6. **Rebake the navmesh on rebase; do not translate it.** `dtNavMesh::m_orig` is private with no setter and separate from `dtNavMeshParams::orig`. `Scene::RebaseNavigation(shift)` shifts the non-`TransformComponent` bake inputs (each `NavMeshBoundsComponent::m_Min/m_Max`, its `OffMeshLink` endpoints, each `NavAgentComponent::m_TargetPosition`), then `BakeNavMesh()` and `SetNavMesh`. `NavMeshGenerator` reads each entity's own `TransformComponent`, so this works before `PropagateWorldTransforms`. [Details](floating-origin-rebase-subsystems-details.md#3-navmesh--crowd--rebake-dont-translate-detours-tile-origin-is-unreachable)
7. **Save the shifted agent targets before the rebake and restore them after.** `SetNavMesh` resets per-agent state including `m_HasTarget` and zeroes `m_CrowdAgentId` (`NavigationSystem` re-registers next tick, per `crowd-manager-follower-parity.md`). The rebake is the one non-cheap rebase step; measure it if nav-heavy scenes hitch. [Details](floating-origin-rebase-subsystems-details.md#3-navmesh--crowd--rebake-dont-translate-detours-tile-origin-is-unreachable)
8. **Keep the recast UBSan exclusion until the vendored tag passes upstream fix #827.** `OloEngine/vendor/CMakeLists.txt` sets target-level `-fno-sanitize=signed-integer-overflow` on the recast targets, because `DetourProximityGrid::hashPos2` (`x*73856093`) overflows `int` beyond ~174 m (benign wrap; recastnavigation#826). Drop it once bumped. [Details](floating-origin-rebase-subsystems-details.md#3-navmesh--crowd--rebake-dont-translate-detours-tile-origin-is-unreachable)
9. **Make terrain streaming entity-relative so a rebase touches nothing.** Feed the streamer `cameraPosition - entityTranslation` so the tile grid and `TerrainTile::WorldOrigin` are anchored to the entity; draw each tile with `tileModel = entityTransform * translate(tile->WorldOrigin)` at every site (`DrawTerrainPatch` and `AddTerrainShadowCaster`, tess and non-tess). `WorldOrigin` was previously never read, stacking all tiles. [Details](floating-origin-rebase-subsystems-details.md#4-terrain-streaming--make-worldorigin-entity-relative-and-its-rebase-free)
10. **Build the non-tessellated terrain cull frustum (`MakeTerrainLocalCullInputs`) per tile from `tileModel`,** not once from the entity transform, or offset tiles are culled at the wrong position and wink in and out. Streamed terrain has no Jolt bodies yet. [Details](floating-origin-rebase-subsystems-details.md#4-terrain-streaming--make-worldorigin-entity-relative-and-its-rebase-free)

## Where the guards are

- `OloEngine/tests/Functional/Scene/WorldOriginRebasePhysicsTest.cpp` (cloth, world-anchored joint, pulley, many-rebase continuity: a missed shift shows as a ~`|shift|` jump).
- `OloEngine/tests/Functional/Navigation/WorldOriginRebaseNavTest.cpp`; `OloEngine/tests/Rendering/PropertyTests/WorldOriginRebaseVisualEvidenceTest.cpp`; `OloEngine/tests/Scene/WorldOriginRebaseBenchmarkTest.cpp`.
- Terrain streaming has no headless guard: verify un-stacking and rebase in the editor.
