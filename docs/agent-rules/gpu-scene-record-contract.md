# GPU Scene records: one key, one generation, one layout on both sides

Contract behind the material, light and environment records (issues #992, #993, #994; children of #977). Read before adding a field to any `GPUScene*` record, before changing what counts as a compatible edit, and before binding a GPU Scene buffer in a pass. Code: `Renderer/GPUScene/GPUSceneTypes.h` (records, encoders, identity rules in the header comment), `GPUScene.h` / `GPUScene.cpp`, `GPUSceneLightAdapter.h`, `Renderer3DGPUScene.cpp`, `HeapBindingSeam.h`, GLSL mirror `include/GPUScene.glsl`.

## Rules

1. **Change a record on the C++ side and the GLSL side in the same commit, address it only by its key, and advance its generation only for an incompatible edit or a removal.** [Details](gpu-scene-record-contract-details.md#gpu-scene-records-one-key-one-generation-one-layout-on-both-sides)
2. **Use the right key.** Material: (owner, slot, source); `Imported` is owned by the mesh source's asset handle (vertex-buffer identity for procedural), `EntityOverride` by the stable entity id with the slot as override lane (an entity with both `MaterialComponent` and an instanced override keeps two records); a source with neither gets `Unresolvable` and extracts nothing. Light: (entity id, light type). Environment: owner, 0 = global IBL. [Details](gpu-scene-record-contract-details.md#1-identity-a-stable-key-a-generation-that-moves-only-for-a-reason)
3. **Advance the generation in place only for an incompatible edit:** a material's closure version, alpha mode, PBR flag or any texture identity (`GPUSceneMaterialTextureIdentity`, `IsCompatibleGPUSceneMaterialEdit`), or an environment texture swap. A light type change is a new key. Removal always advances and retires the slot for `RetirementFrameCount` frames. [Details](gpu-scene-record-contract-details.md#1-identity-a-stable-key-a-generation-that-moves-only-for-a-reason)
4. **Test `Active` as well as the generation.** A slot whose generation would wrap keeps its last generation on the tombstone and is never reused. An owner-token change (scene reload, backend switch) resets every kind and drops every resolved heap offset. [Details](gpu-scene-record-contract-details.md#1-identity-a-stable-key-a-generation-that-moves-only-for-a-reason)
5. **Update the struct, its `static_assert` lines, the GLSL struct and the pin table in `GPUSceneLayoutTest.cpp` together.** Mechanism A: the `static_assert` block in `GPUSceneTypes.h`. Mechanism B: `GPUSceneLayoutTest.ShaderStorageLayoutsMatchCppRecords` reflects `include/GPUScene.glsl` via SPIRV-Cross and compares names, offsets, size and std430 stride against the C++ `offsetof` table. [Details](gpu-scene-record-contract-details.md#2-layout-parity-two-mechanisms)
6. **Bind a GPU Scene buffer immediately before its consumer, pass-locally, taking only the kinds you read.** `GPUSceneBindingLayout` aliases: instances, geometries, materials at 15, 16, 17 (instance-cull trio); lights and environments at 9 and 10 (Forward+ per-type buffers). Use `GPUScene::BindMaterials()` and siblings; `GPUScene::Bind()` takes all five and is only for a consumer reading all five. [Details](gpu-scene-record-contract-details.md#3-the-binding-namespace-is-full-take-one-kind-at-a-time-pass-locally)
7. **Declare no storage block in `include/GPUScene.glsl`;** each kind has its own one-line declaration file (`include/GPUSceneMaterials.glsl` and four siblings). [Details](gpu-scene-record-contract-details.md#3-the-binding-namespace-is-full-take-one-kind-at-a-time-pass-locally)
8. **Call `CommandDispatch::InvalidateGPUSceneMaterialBinding()` whenever something else takes slot 17.** `GPUFrustumCuller` shares it with the draw-indirect buffer; otherwise the next linked draw reads draw commands as materials. [Details](gpu-scene-record-contract-details.md#3-the-binding-namespace-is-full-take-one-kind-at-a-time-pass-locally)
9. **Do not delete `GPUSceneLayoutTest.NoBindingCarriesTwoDifferentStorageBlocksInOneShader`;** on failure, split includes or renumber. It fails when one binding carries two differently named storage blocks in one shader (`InstanceBlock.glsl` and `InstanceBlock_Vertex.glsl` both declare `InstanceBuffer` at 15 legitimately, one per stage). The layout test's own output block uses 19. [Details](gpu-scene-record-contract-details.md#3-the-binding-namespace-is-full-take-one-kind-at-a-time-pass-locally)
10. **A consumer that reads `GPUSceneHeapOffsetUnresolved` binds through the slot path.** Records carry each texture as an RHI handle plus a heap offset from `HeapBinding::ResolveRecordTextureOffset` (persistent, skipped when the heap is disabled). Compatibility compares texture identity, never the offset; mint material 2D textures with `HeapBinding::MaterialTexture2DSampler` so a texture never has two descriptors. Assume no shader-side bindless (#805). [Details](gpu-scene-record-contract-details.md#4-textures-an-rhi-handle-plus-a-persistent-heap-offset-no-bindless-promise)
11. **Do not add a second extraction site for a kind that has one.** Materials: `Renderer3D::ResolveGPUSceneMaterialKey` (same `ResolveSubmeshMaterialOrigin` decision as the drawn material) and `Renderer3D::ExtractGPUSceneMaterial` (early return once `GPUScene::IsMaterialStaged`); materials commit before instances. Lights: `Scene::ProcessScene3DSharedLogic` via one `MakeGPUSceneLightInput` per component type, regardless of `MultiLightUBO::MAX_LIGHTS`. Environment: `Renderer3D::ExtractGPUSceneEnvironment` at `EndScene`; no published environment, no record. A new field extends the field-inventory comment in `GPUSceneTypes.h`. [Details](gpu-scene-record-contract-details.md#5-extraction-each-record-kind-has-one-producer)
12. **Read the authored light once into `GPUSceneLight` and derive raster structs through `GPUSceneLightAdapter`.** A new light field goes into `GPUSceneLightInput`, `EncodeGPUSceneLight`, the record, the GLSL mirror and the adapter, never the raster packing alone (see `light-path-photometric-parity.md`, rule 2). `GPUSceneLightAdapterTest.cpp` pins bytes per type including `kNoShadowEntry`; shadow atlas / VSM layer base is patched in afterwards. [Details](gpu-scene-record-contract-details.md#6-the-raster-light-adapter)
13. **A migrated draw carries a link to its record, resolved exactly once, after the registry commits and before any pass reads a buffer.** Order (`GPUScene/GPUSceneDrawLink.h`): `BeginGPUSceneExtraction` clears the table; `ExtractGPUSceneMesh` stages and returns a link index; `DrawMesh` carries it in the packet; `EndScene` runs `EndExtraction`, `Upload`, `ResolveGPUSceneDrawLinks`; dispatch reads resolved links only and never resolves a key. [Details](gpu-scene-record-contract-details.md#7-the-raster-consumer-a-draw-link-resolved-once-per-frame)
14. **A link that does not resolve must still draw** (both generation lanes of `InstanceData::GPUSceneRef` read zero, reserved invalid; consumer falls back). `RendererProfiler` shows resolved and unresolved counts. [Details](gpu-scene-record-contract-details.md#7-the-raster-consumer-a-draw-link-resolved-once-per-frame)
15. **Do not shift a resolved record's transform again.** Records are render-relative; `DecodeGPUSceneTransform` is the one place affine rows become a `glm::mat4`. [Details](gpu-scene-record-contract-details.md#7-the-raster-consumer-a-draw-link-resolved-once-per-frame)
16. **Read a raster material only through `oloGPUSceneMaterial`** (`include/GPUSceneMaterialResolve.glsl`), which validates the generation before the slot. [Details](gpu-scene-record-contract-details.md#7-the-raster-consumer-a-draw-link-resolved-once-per-frame)
17. **Name every previous-frame-transform duplicator in `GPUScene/GPUSceneLegacyAdapters.h`.** `GPUSceneAntiDuplicationRatchetTest` fails on an unnamed duplicator and on a named file that stopped duplicating; before adding an entry, ask whether the path can take a link. [Details](gpu-scene-record-contract-details.md#7-the-raster-consumer-a-draw-link-resolved-once-per-frame)
