# Component scene-serializer codegen — the eligibility rule, the annotations, and the one blind spot

OloHeaderTool generates the per-component serialize/deserialize blocks in `Scene/SceneSerializer.cpp` (and the other component touch-points). Read before adding a component field, widening the classifier, or reaching for a `kComponentsCustomSerialize` exclusion.

## Rules

1. **Follow the touch-point table for every component add or change.** It lists what OloHeaderTool generates and what is still yours (save-game `Serialize` + `RegisterAll`, Lua `RegisterAllTypes`, editor `DrawComponent<T>` / `DisplayAddComponentEntry<T>`, `OLO_PROPERTY`, hand-written copy ctor / `operator==`); the pre-commit hook catches none of these. [Details](component-serializer-codegen-details.md#0-adding-or-changing-a-component-every-touch-point)
2. **Add every new field to a hand-written copy ctor, copy-assignment and `operator==`.** They are per-field lists (components holding `Ref<T>` runtime state, e.g. `TerrainComponent`); a miss reverts the value on Play (`Scene::Copy`) and hides it from undo. Guard with a `Scene::Copy` round-trip plus one mutation per field, like `TerrainVirtualTextureFieldsSurviveSceneCopy`. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
3. **Hand-write the save-game, Lua and editor touch-points; no test guards them.** Without the `Serialize` overload and `RegisterAll` entry the save-game drops the component; without `DrawComponent<T>` / `DisplayAddComponentEntry<T>` (in `OloEditor/src/Panels/SceneHierarchyPanel.cpp`) it is invisible in the editor. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
4. **Never name a helper struct `*Component`.** Any struct ending in `Component` is swept into every generated list and breaks unrelated TUs (`C2065`, `C3544`); use another suffix and rebuild `GenerateBindings`. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
5. **After widening the classifier, rebuild `GenerateBindings` and diff the generated `.inl`.** Every slice flipped components nobody predicted; the diff is the only thing that catches a newly flipped component that omits a field, clamps on load or is runtime-only. [Details](component-serializer-codegen-details.md#5-the-guards--and-the-one-blind-spot)
6. **Add a component persisted some other way than a sub-map to `kComponentsCustomSerialize` by hand.** `IDComponent` (top-level `Entity:` line) is invisible to both coverage checks and would get a bogus sub-map plus a double `AddComponent`. [Details](component-serializer-codegen-details.md#5-the-guards--and-the-one-blind-spot)
7. **Generate a component only when every non-skipped member is serializer-trivial and public.** Otherwise the parser skips it automatically with no exclusion entry; a non-public member (e.g. `TransformComponent`) fails safe. [Details](component-serializer-codegen-details.md#2-the-eligibility-rule)
8. **Hand-write a block only for a non-trivial field or for logic the plain round-trip drops.** The second case (cross-field invariant, `Sanitize*` call, non-`m_`-stripped key, entity identity) also needs a `kComponentsCustomSerialize` entry. A plain range clamp or runtime-field omission is not a reason; use `Clamp` / `Reject` / `Skip`. [Details](component-serializer-codegen-details.md#4-when-you-must-still-hand-write-a-block)
9. **Mark runtime-only fields `OLO_SERIALIZE(Skip)`.** It composes with `OLO_PROPERTY` in either order; without it every individually trivial runtime field starts round-tripping (as for `NavAgentComponent`'s nav state). [Details](component-serializer-codegen-details.md#olo_serializeskip)
10. **Use `OLO_SERIALIZE(Clamp, Min=..., Max=...)` for continuous quantities and `Reject` for discriminated ones.** Clamp supports scalar `Float`/`Int`/`UInt`/`SmallInt`/`SmallUInt`/`Enum` and `glm::vec3`; give at least one bound. `Reject` (scalars only, not vec3, exclusive with `Clamp`) leaves the constructor default on an out-of-range or non-finite value, on both the YAML and `.scenebin` read paths; keep `EmitBinaryReadFields` and `EmitBinaryWriteFields` field-for-field aligned. Pinned by `ComponentRoundTrip.VehicleDriveModeRejectsOutOfRangeToTheDefault`. An unsupported type marks the component non-trivial. [Details](component-serializer-codegen-details.md#olo_serializereject-min-max)
11. **Widen small ints (`u8`, `u16`, `i8`, `i16`) to `u32`/`i32` on emit.** yaml-cpp writes a raw char otherwise; read with `.as<decltype(member)>`. [Details](component-serializer-codegen-details.md#type-specific-rules-that-are-not-optional)
12. **Sort unordered containers before writing, and use sortable set elements.** Sets accept `bool`, `int`, `u32`, `u64`, small ints, `AssetHandle`, `std::string`, `enum` (never float, glm, struct; `AssetHandle` sorts via `static_cast<u64>`); maps are `std::unordered_map<std::string, V>` with V not a nested struct. Otherwise `ComponentRoundTrip.SerializeLoadSerializeProducesIdenticalYAML` breaks. [Details](component-serializer-codegen-details.md#type-specific-rules-that-are-not-optional)
13. **Keep the generator's views of the source consistent.** Enums match by leaf name (`CollectEnumTypes`); nested structs must be non-empty, acyclic and all-trivial public (`ClassifyStruct`); the statement-splitter ends at a brace-depth-0 `}`. Not handled (component auto-skipped): `std::array`, non-string-keyed maps, sets of non-sortable elements, vectors of non-trivial structs, `Ref<T>` of non-`Asset` types. [Details](component-serializer-codegen-details.md#nested-structs)
14. **Pick the right exclusion set.** `kComponentsCustomSerialize` is unrelated to the tuple, save-game, on-add and on-remove sets (`kComponentsNotInTuple`, `kComponentsNotInSaveGame`, `kComponentsCustomOnAdd`, `kComponentsCustomOnRemove`); each is mirrored by a coverage test. `kComponentsNotFieldEditable` and `kHandWrittenFieldClamps` are shared by the MCP and visual-script field registries; split one only with a reason in the same commit. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
15. **Add a component in a new subsystem directory to two test allowlists.** `ComponentHeaderRoots()` in `ComponentTupleCoverageTest.cpp` and `ComponentSerializerCoverageTest.cpp`; and repoint a coverage test's text parser when a touch-point moves into a generated file. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
16. **Audit snapshot and duplication policy for a component with a custom copy constructor or removal hook.** `AutomationComponentRegistry.cpp` specializes terrain resources, generated LOD ownership and unsaved animation graphs. [Details](component-serializer-codegen-details.md#7-every-generated-touch-point-its-exclusion-set-and-what-stays-hand-maintained)
17. **Keep the components that are deliberately hand-written hand-written.** Examples: `LODGroupComponent` (flattened keys), `NavMeshBoundsComponent`, `LightProbeVolumeComponent`, `StreamingVolumeComponent`, `PhysicsJoint3DComponent`, `SphereAreaLightComponent`, `ProceduralSkyComponent`, `MorphTargetComponent`, `Rigidbody3DComponent`, the three runtime `*StateComponent`s and `IDComponent`. [Details](component-serializer-codegen-details.md#4-when-you-must-still-hand-write-a-block)
18. **Mirror new emitted shapes in the codegen tests.** `ContainerSerializerCodegenTest.cpp` and `NestedStructSerializerCodegenTest.cpp` cover shapes no live component uses yet. Edit generated output only via the tool, never `Scripting/C#/Generated/`. [Details](component-serializer-codegen-details.md#5-the-guards--and-the-one-blind-spot)
