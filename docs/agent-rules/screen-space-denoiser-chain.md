# The screen-space denoiser chain

Rules for touching the SSGI / SSR denoiser stages (trace, pre-blur, temporal resolve, post-blur, guided upscale): `SSGIRenderPass`, `SSRRenderPass`, `PostProcess_SSGI*.glsl`, `PostProcess_SSR*.glsl`, and `include/SpatialDenoise.glsl` (issue #708). The sampler and the resolve themselves are in stochastic-sampling-and-temporal-resolve.md.

## Rules

1. **Guide every stage by the guide attachment the trace writes, never by the full-resolution G-Buffer.** The chain runs at the trace band (half the scene band when `SSGIHalfResolution` is on); `PostProcess_SSGI.glsl` writes a second attachment packed like G-Buffer RT1 (`rg` octahedral normal, `b` roughness, `a` AO). `SSGISurfaceHistory` is extracted from it. Only the guided upscale reads both. [Details](screen-space-denoiser-chain-details.md#1-a-stage-that-runs-at-a-different-resolution-than-the-g-buffer-needs-its-own-guide)
2. **Read octahedrally-encoded normals and the trace's centre depth/normal/albedo with `texelFetch` (at `FullResTexel(uv)`), never `texture()`.** Bilinear taps interpolate across the oct fold or average foreground with background depth; only the ray march uses filtered lookups. [Details](screen-space-denoiser-chain-details.md#2-sample-the-guide-with-texelfetch-never-texture)
3. **Measure a tap's geometry as plane distance along the centre normal (`OloDenoisePlaneWeight`), never as a view-depth difference.** The tolerance is relative to view depth and numerically equal to the resolve's `SSGI_DEPTH_TOLERANCE`. Pinned by `ScreenSpaceDenoiseMath.PlaneWeightKeepsGrazingCoplanarTaps`. [Details](screen-space-denoiser-chain-details.md#3-the-geometry-test-is-a-plane-distance-not-a-depth-difference)
4. **Hash any setting that changes a chain resource's size into the blackboard fingerprint and invalidate the temporal histories; hash nothing for a UBO-only value.** `SSGIHalfResolution` resizes signal targets, blur scratch and all four SSGI histories (the #530 class, render-pipeline-caches.md). A blur radius of 0 skips the draw but still declares the resource, so the radius stays out of the fingerprint. [Details](screen-space-denoiser-chain-details.md#4-resolution-is-a-graph-topology-input-a-radius-is-not)
5. **Make `ExtractHistoryTexture` read the temporal resolve's attachment, never the post-blur's.** Accumulating a filtered copy compounds the filter and bakes disocclusion widening into the history. [Details](screen-space-denoiser-chain-details.md#5-the-history-takes-the-resolves-output-never-the-post-blurs)
6. **Do not fold two stages into one shader.** Each stage gathers a neighbourhood of the previous one, so five stages are five draws, in one render-graph node (the `CloudscapeRenderPass` shape) with `AllowSamePassReadWrite` on each intermediate. [Details](screen-space-denoiser-chain-details.md#6-every-stage-needs-its-input-in-a-real-texture)
7. **Guide a specular filter on roughness (`OloDenoiseRoughnessRadius`, 0 below the knee), never on variance.** A mirror's high-contrast reflection is legitimately high-variance. SSR gets no half-resolution trace, no upscale and no quad ray distribution (one VNDF sample per pixel). [Details](screen-space-denoiser-chain-details.md#7-what-transfers-from-a-diffuse-denoiser-to-a-specular-one-and-what-does-not)
8. **Weight both SSR spatial stages with `OloDenoiseSpecularTapWeight`, not plane distance and normal alone.** `PostProcess_SSR.glsl` writes a zero delta above its roughness cutoff yet a valid guide, so geometry-only filtering averages the zeros into a dark band at a polished/rough seam. The cutoff arrives in `DenoiseGuide.w`; a stage that does not read it reverts silently. Pinned by `ScreenSpaceDenoiseMath.SpecularTapWeightRejectsWhatTheTraceExcluded`. [Details](screen-space-denoiser-chain-details.md#7a-a-specular-tap-needs-a-roughness-test-as-well-as-a-geometric-one)
9. **Keep the pre-blur radius at about 1 trace-band pixel unless an energy-preserving firefly pre-filter precedes it.** Radius 2 makes visible blobs while every noise metric calls it better (radius 1 keeps 97% of the reduction). Judge it on a ~120x90 crop scaled 4x nearest-neighbour. Re-measure after any kernel change. [Details](screen-space-denoiser-chain-details.md#8-a-pre-blur-turns-sparse-hemisphere-noise-into-blobs-keep-its-radius-small)
10. **Push every disc tap at least one texel off the centre with `OloDenoiseTapOffset`; never `ivec2(round(offset))`.** Poisson magnitudes of 0.16-0.95 round onto the centre and count it several times. Pinned by `ScreenSpaceDenoiseMath.EveryDiscTapLandsOffTheCentreTexel`. [Details](screen-space-denoiser-chain-details.md#8a-a-disc-tap-that-rounds-to-00-is-the-centre-counted-twice)
11. **Rotate a stratum-grid split across neighbouring pixels per frame index.** A per-pixel-fixed phase covers exactly 1/4 of the domain forever, a bias no temporal resolve removes; rotate by a whole stratum. [Details](screen-space-denoiser-chain-details.md#9-a-per-pixel-fixed-stratum-phase-is-a-bias-not-noise)
12. **Register every new `layout(binding = N) uniform sampler2D u_Foo` in `ShaderBindingLayout::IsKnownTextureBinding` for slot N.** Otherwise `ShaderReflectionBindingTest` fails; the same name at different slots needs one entry per slot. [Details](screen-space-denoiser-chain-details.md#10-register-every-new-texture-binding-name)
13. **Validate the changed shaders with `glslc` before spending a build.** Split each `#type` section into a temp file in the shader's own directory and run `glslc` with no `-I` (see `validate-shaders-with-glslc-first` in the memory store). [Details](screen-space-denoiser-chain-details.md#11-validate-the-shaders-with-glslc-before-spending-a-build)
14. **Do not guide on variance of the raw trace; the chain reads the temporally accumulated variance, relative to the mean.** It also uses a view-depth-relative geometry tolerance rather than the reference's pixel-width scaling, because the chain filters at two resolutions. [Details](screen-space-denoiser-chain-details.md#appendix-the-reference-this-is-derived-from)
