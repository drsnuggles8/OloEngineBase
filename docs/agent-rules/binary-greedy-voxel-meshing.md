# Binary greedy meshing + packed quads

Issue #727. The cubic voxel mesher: `Terrain/Voxel/VoxelGreedyMesher.{h,cpp}` (merge), `VoxelQuad.h` (encoding), `VoxelGreedyMeshBuilder.{h,cpp}` (async rebuild + GPU upload) and the three `Terrain_VoxelGreedy*.glsl` shaders. Read before touching any of them; every item is a way to get a plausible-looking wrong frame or silently dropped geometry.

## Rules

1. **Change `VoxelQuad.h` and `include/VoxelQuadUnpack.glsl` together.** Bit layout, face numbering and the per-face U/V basis are one contract written twice; the layout derives from `VoxelChunk::CHUNK_SIZE` in C++ and is hard-coded in GLSL, and the C++ `static_assert` fires only on a chunk-size change, not a hand edit. [Details](binary-greedy-voxel-meshing-details.md#1-the-encoding-is-a-contract-with-the-gpu-mirrored-in-a-second-file)
2. **Keep extents biased by one.** A full-span run at a 32-voxel chunk would encode as 0 and vanish; `VoxelQuadEncoding.FullSpanExtentSurvivesTheRoundTrip` fails if the bias is simplified away. [Details](binary-greedy-voxel-meshing-details.md#1-the-encoding-is-a-contract-with-the-gpu-mirrored-in-a-second-file)
3. **Keep `cross(U, V) == normal` in `VoxelFaceBasis`, and keep `kWidthIsInnerExtent` per face.** Swapping U and V inverts a quad (a hole seen from certain angles); Width/Height is not uniform across faces, and a wrong choice transposes a 1x8 strip into 8x1. Pinned by `VoxelFaceBasisContract.CrossOfUAndVIsTheOutwardNormal`; `VoxelGreedyMeshVisualEvidenceTest` shoots four angles including from below. [Details](binary-greedy-voxel-meshing-details.md#2-swapping-a-faces-u-and-v-does-not-lose-a-quad--it-inverts-it)
4. **Choose the reference axis before crossing for tangents.** Cubic normals are exactly axis-aligned, so `normalize(cross(N, vec3(0,0,1)))` is NaN on every +/-Z face and a post-hoc `length(T) < 0.001` rescue cannot fire; use `abs(N.z) < 0.99 ? +Z : +X`. [Details](binary-greedy-voxel-meshing-details.md#2b-an-exact-axis-aligned-normal-breaks-two-idioms-copied-from-the-other-terrain-shaders)
5. **Check that the normal-map array is bound before decoding a texel.** An unbound sampler reads black, `black * 2 - 1` is a unit-length `(-1,-1,-1)` that rotates normals ~55 degrees and renders the mesh black. Blend in 0..1 texel space and decode after. Shoot a PNG of a normal-map-bound cubic scene. [Details](binary-greedy-voxel-meshing-details.md#2b-an-exact-axis-aligned-normal-breaks-two-idioms-copied-from-the-other-terrain-shaders)
6. **Keep padding uniform on all three axes.** `VoxelNeighbourhood` uses u64 columns for a 34-bit padded span so +/-Y is not special; do not give one axis its own path. Edge and corner cells are never read (only face-neighbours); needing 26 neighbours means misreading the algorithm. Tests: `VoxelGreedyMesherBoundary.EveryAxisCullsAgainstItsNeighbour`, `PartialNeighbourCullsOnlyTheCoveredFaces`. [Details](binary-greedy-voxel-meshing-details.md#3-padding-is-uniform-on-all-three-axes-here--deliberately)
7. **Rebuild the six neighbours' meshes when a chunk is edited, without setting their `Dirty` flags.** `VoxelGreedyMeshBuilder::DispatchDirty` rebuilds the ring; setting the flag would cascade outward every frame. Skipping the ring leaves a stale wall at chunk seams. [Details](binary-greedy-voxel-meshing-details.md#4-editing-a-chunk-invalidates-its-six-neighbours-meshes-not-just-its-own)
8. **Keep the mesher a pure function of an immutable snapshot.** `VoxelGreedyMesher::Gather` runs on the thread owning the `VoxelOverride` and yields a self-contained `VoxelNeighbourhood`; never capture the `VoxelOverride` on the worker (a concurrent `CarveSphere` tears reads). The game thread does only the gather and the GPU upload. [Details](binary-greedy-voxel-meshing-details.md#5-the-mesher-is-a-pure-function-of-an-immutable-snapshot--that-is-the-thread-safety-design)
9. **Run uploads during `Scene::ProcessScene3DSharedLogic`, before `RenderPipeline::PrepareFrame`.** `OpenGLVertexArray::AddInstanceBuffer` is non-DSA and leaves a VAO and `GL_ARRAY_BUFFER` bound; interleaving an upload with bucket execution stales `CommandDispatch`'s `CurrentBoundVAO` cache. Foliage shares this invariant. [Details](binary-greedy-voxel-meshing-details.md#5-the-mesher-is-a-pure-function-of-an-immutable-snapshot--that-is-the-thread-safety-design)
10. **Define `OLO_INSTANCE_SINGLE` before including `InstanceBlock_Vertex.glsl` in the greedy shaders.** The chunk uploads one `InstanceData` entry while `gl_InstanceIndex` counts quads; without it the read runs `224 x quadIndex` bytes into a 224-byte upload (garbage on GL, device loss on Vulkan, as the #691 foliage fault). [Details](binary-greedy-voxel-meshing-details.md#6-gl_instanceindex-is-the-quad-index-not-an-instancedata-index)
11. **Keep quads in chunk-local voxel units and put placement in the model matrix once.** World placement is `terrainTransform x translate(chunkOrigin) x scale(voxelSize)`, built in `VoxelGreedyMeshBuilder::UploadMesh` and combined at the draw site in `Scene.cpp`; applying it twice or also baking the origin into quads renders a correct world somewhere else. [Details](binary-greedy-voxel-meshing-details.md#7-the-chunk-origin-and-voxel-size-ride-the-model-matrix)
12. **Unpack the shadow silhouette through the same `VoxelQuadUnpack.glsl`.** `Terrain_VoxelGreedyDepth.glsl` must not grow its own copy. `ShadowVoxelCaster::instanceCount` selects the depth shader; bind lazily when the shader changes, never hoist a single `Bind()` out of the loop. [Details](binary-greedy-voxel-meshing-details.md#8-the-shadow-silhouette-must-be-rebuilt-by-the-same-code-as-the-lit-one)
13. **In `m_VoxelMesher == GreedyCubic`, seed the volume from the height field and hide the heightfield surface.** `VoxelOverride::SeedFromHeightmap`, and `heightfieldSurfaceHidden` in `Scene.cpp`; marching cubes leaves the volume sparse. If cubic slopes shimmer, check the second first. [Details](binary-greedy-voxel-meshing-details.md#9-in-cubic-mode-the-voxels-are-the-terrain)
14. **Treat an empty `VoxelChunk::MaterialData` as material 0 everywhere, a second merge implementation.** Keep `VoxelGreedyMesher.UniformMaterialTakesTheSameResultAsAnExplicitZeroArray`; a merge ignoring materials produces the right face set with the wrong material. [Details](binary-greedy-voxel-meshing-details.md#10-materials-the-empty-array-is-a-fast-path-not-an-absence)
15. **Compare face sets, not quad counts.** `VoxelGreedyMesherFaceSet.GreedyFaceSetMatchesNaive` expands quads to unit faces and compares the multiset both ways plus per-key counts; `MeshNaive` shares no code with `Mesh` on purpose. [Details](binary-greedy-voxel-meshing-details.md#11-comparing-quad-counts-is-not-comparing-face-sets)
