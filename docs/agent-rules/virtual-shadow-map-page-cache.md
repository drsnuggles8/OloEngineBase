# Virtual Shadow Maps: the page cache has four invariants, and breaking one is invisible

Rules for the VSM page table, clip projections and the code that decides which clip level or local mip a position belongs to. Every violation still renders a frame; the shadows are wrong in a way that looks like a different bug.
Applies to: `OloEngine/src/OloEngine/Renderer/Shadow/VirtualShadowMap.{h,cpp}`, `OloEditor/assets/shaders/include/VirtualShadow*.glsl`, `compute/VSM_*.comp`, `VSM_Depth*.glsl`.
If VSM renders no shadow while every diagnostic says it is up, read rule 1 first.

## Rules

1. **Never branch on a runtime setting in a pass's `Setup()`.** `RenderGraph::BuildFrameGraph(fingerprint)` caches `Setup()` and the fingerprint excludes pass settings, so toggling VSM on later leaves `m_SceneDepth` invalid and the frame unshadowed with no error. Declare resources unconditionally and gate work in `Execute()`; `IsEnabled()` must answer "could it ever run" (`m_ShadowMap != nullptr`). Passes that must branch: [render-graph-setup-declaration-gates.md](render-graph-setup-declaration-gates.md). Use DebugMode 7 (`Shadow factor`) to separate this from a page-table fault. [Details](virtual-shadow-map-page-cache-details.md#5-a-render-graph-passs-setup-is-cached--it-must-not-branch-on-a-setting)
2. **Make marker and sampler pick the same clip level through one function.** Both call `vsmClipLevelForDistance` (`include/VirtualShadowCommon.glsl`, C++ twin `VirtualShadowMap::SelectClipLevel`); never inline it. Mark the selected level AND the next coarser one, and upload the same `u_VSMCameraPosition` on both sides. A mismatch reads fully lit. [Details](virtual-shadow-map-page-cache-details.md#1-the-producer-and-the-consumer-must-pick-the-same-clip-level)
3. **Anchor every clip level's depth range at the render origin, never the camera.** Use `glm::ortho(minX, minX + extent, minY, minY + extent, -depthRange, +depthRange) * lightView`; levels differ only in XY extent (`VirtualShadowMap.AllClipLevelsAgreeOnTheDepthOfAWorldPoint`). `VirtualShadowMapSettings::DepthRange` is scene-scale; `SetSettings` sets `m_FullInvalidate` when it moves. [Details](virtual-shadow-map-page-cache-details.md#2-the-depth-range-must-not-follow-the-camera)
4. **Give `VSM_FreeWrappedPages.comp` both `PrevPageOffset` and the unwrapped `PageDelta`.** Offsets are stored modulo the table resolution, so a move of one table width looks like no move. Use a POSITIVE modulo (`NegativeCameraCoordinatesStillProduceInBoundsPageOffsets`), and translate a caster footprint by `PageOffset` before the HPB lookup in `VSM_CullCasters.comp` (the HPB is reduced in wrapped space). [Details](virtual-shadow-map-page-cache-details.md#3-toroidal-addressing-needs-both-offsets-not-just-the-delta)
5. **Keep marking one frame behind and keep the coarser-level fallback loop in `vsmShadowFactor`.** It is the anti-pop-in mechanism. Marking is the late `VirtualShadowMapMarkPass`. `VSM_EndFrame.comp` clears `VISITED` after the raster and before marking. A still scene should settle to `pages drawn` near 0 in the Renderer Settings panel. [Details](virtual-shadow-map-page-cache-details.md#4-marking-runs-one-frame-behind-and-the-fallback-is-the-feature)
6. **Do not add a depth attachment or per-level draws to the VSM raster.** It uses no depth buffer, `imageAtomicMin` into an R32UI pool, a never-written 4096² R8UI raster-scope attachment (draw buffers `GL_NONE`), and one indirect draw per caster batch for all sixteen levels. The clip level travels in the instance record; never use `gl_BaseInstance` ([glsl-shaders.md](glsl-shaders.md) §5c-bis), pass the run base in a uniform. [Details](virtual-shadow-map-page-cache-details.md#6-why-the-raster-looks-nothing-like-the-csm-pass)
7. **Key caster footprints stably and hash only consumed inputs.** Keep stable scene instance/part keys in `ShadowCasterFootprint`; terrain hashes tessellation/morph and height content, greedy voxel uploads bump a geometry revision, and VT feedback slots and material parameters must not invalidate (`ShadowFamilyCache.TerrainFeedbackAndMaterialChangesReuseTheSilhouette`). Foliage motion: [foliage-vsm-page-caching.md](foliage-vsm-page-caching.md). Callers without bounds dirty the whole domain. [Details](virtual-shadow-map-page-cache-details.md#7-caster-coverage)
8. **Check the caster matrix before promising VSM coverage.** Virtual geometry reaches clip levels only, not local-light layers (see [virtual-geometry-into-a-second-shadow-technique.md](virtual-geometry-into-a-second-shadow-technique.md)); enabling VSM replaces CSM, `LocalLights` also replaces the local atlas. Evidence: `ShadowFamilyVisualEvidence`; shader compilation alone does not prove backend parity, so keep per-backend live captures. Verify Forward, Forward+ and Deferred on Vulkan with fresh frames and light-casting controls. [Details](virtual-shadow-map-page-cache-details.md#7-caster-coverage)
9. **Run `VulkanPassSuite.VirtualShadowMapRunsAFullFrameOnVulkan` when extending VSM.** It is the only test executing this code on Vulkan. Assume any `#ifdef OLO_VULKAN` shader branch is unparsed until you name what parses it. VSM needs an `R32UI` `ImageFormat`, and must not restore a viewport that `GetViewport()` reports as `{0,0,0,0}`. [Details](virtual-shadow-map-page-cache-details.md#7-caster-coverage)
10. **Keep two projection flavours and undo the Vulkan y flip in the raster stage.** `ViewProjection` (math) and `ViewProjectionRaster` (`RHI::AdjustProjectionForBackend`) sit at different offsets (`VirtualShadowMap.GPUStructLayoutsMatchTheirShaderTwins`); only the depth raster's `gl_Position` reads the second. `VirtualShadowRasterStage.glsl` undoes `fragCoord.y_vulkan = RES - fragCoord.y_gl` under `#ifdef OLO_VULKAN`, so the pool is backend-identical; do not flip the sample instead. [Details](virtual-shadow-map-page-cache-details.md#7-caster-coverage)
11. **For mipped local layers, flip about the instance's own resolution.** Use `rasterRes = LOCAL_RES >> mip`, not `VSM_LOCAL_VIRTUAL_RESOLUTION` (`TheLocalRasterStageFlipsAboutItsOwnMipResolution`). [Details](virtual-shadow-map-page-cache-details.md#the-vulkan-y-flip-is-per-instance-when-the-raster-is-mipped)
12. **Make local marker and sampler agree on the MIP.** Both call `vsmLocalMipForDistances` from the same `u_VSMCameraPosition`; mark the selected mip and the next coarser (`TheMarkerAndTheSamplerCallOneMipHeuristic`). Every mip of a layer shares one projection, so there is no local `DepthRange`. [Details](virtual-shadow-map-page-cache-details.md#8-local-lights-are-a-second-addressing-domain-and-four-invariants-change-shape)
13. **Do not use toroidal addressing for local layers.** Layers do not wrap; a moved light raises the layer's invalidate flag. [Details](virtual-shadow-map-page-cache-details.md#8-local-lights-are-a-second-addressing-domain-and-four-invariants-change-shape)
14. **Cull perspective layers in clip space against the six frustum planes, with no divide.** Fall back to the full page grid when a corner is behind the plane (`VSM_CullLocalCasters.comp`, local half of `VSM_InvalidatePages.comp`); dividing by `w <= 0` makes casters vanish near the light. [Details](virtual-shadow-map-page-cache-details.md#8-local-lights-are-a-second-addressing-domain-and-four-invariants-change-shape)
15. **Project face UV with `vsmProjectIntoLocal`.** Reject beyond 1e-3 of a face, clamp the rest: a plain range test leaves seam lines on cube edges, a plain clamp marks a sphere for spot cones. Marker and sampler both call it. [Details](virtual-shadow-map-page-cache-details.md#8-local-lights-are-a-second-addressing-domain-and-four-invariants-change-shape)
16. **Wire three local-light touch-points.** `ShadowMap::AnyShadowsRequested()` must count local lights (atlas count is zero by construction); `VSM_InvalidatePages.comp` needs a local half; decode meta owners only through `vsmMetaOwnerPageIndex`. [Details](virtual-shadow-map-page-cache-details.md#three-touch-points-outside-the-page-table-that-a-local-light-needs)
17. **Remember `u_AtlasEntryCount` is zero with local lights on the page table.** Any `entry < u_AtlasEntryCount` branch is dead. `DDGI_Relight.glsl` and `compute/FroxelFogScatter.comp` are deliberately unconverted; a compute pass needs its own `VirtualShadowMap::BindForSampling` publish, not an assumed surviving binding. [Details](virtual-shadow-map-page-cache-details.md#who-still-reads-the-atlas-and-why-that-is-not-a-bug-list)
18. **Dispatch (something x layers) kernels in 2D.** `GL_MAX_COMPUTE_WORK_GROUP_COUNT` is only guaranteed 65,535 per dimension; local invalidation is 1024 x 256. [Details](virtual-shadow-map-page-cache-details.md#a-compute-dispatch-over-something-x-layers-can-exceed-the-work-group-limit)
19. **Do not bound the local raster's discarded fragments without a profile.** One draw per (batch, mip) costs six indirect commands per batch. [Details](virtual-shadow-map-page-cache-details.md#the-known-cost-so-it-is-not-rediscovered-as-a-bug)
20. **Multiply by a "coarser" bias; assert its direction.** `LocalDetailBias` > 1 must push to coarser mips. Test direction (not just `>=`) at an operating point where nothing clamps. [Details](virtual-shadow-map-page-cache-details.md#a-bias-that-reads-naturally-either-way-will-be-inverted-half-the-time)
21. **Declare each buffer block once, macroing the qualifier,** and check shaders with `glslc` (`-fshader-stage=... -I include`, also `-DOLO_VULKAN=1`). [Details](virtual-shadow-map-page-cache-details.md#two-glsl-habits-this-issue-punished)
