# Terrain virtual texturing — the invariants, and what breaks quietly

Rules for `OloEngine/src/OloEngine/Terrain/VirtualTexture/`, `OloEditor/assets/shaders/compute/TerrainVT*.comp`,
`include/TerrainVirtualTexture.glsl`, `TerrainLayerBlend.glsl`, `TerrainParamsBlock.glsl`. Every defect here is a wrong address, which looks like a slightly different texture, not an error.

## Rules

1. **Never add a `ClientWaitFence` or any wait to the readback.** Use the `IsFenceSignaled` poll, read only signalled ring slots, keep more than one slot, never read the feedback SSBO directly (use `RHI::MemoryResidency::DeviceToHost` + `ReadBufferSubData`; the persistent mapping is write-only). `PollReadback` walks from `m_NextReadbackSlot`; `RetireAnalysis` adopts by sequence number. [Details](terrain-virtual-texturing-details.md#2-there-is-no-clientwaitfence-in-this-class-and-there-must-not-be)
2. **Keep all three parts of the coarse-mip fallback.** (a) The fill kernel runs coarsest to finest, one dispatch per level with a barrier, no alpha 255 on inherited entries. (b) `oloVTVirtualToPhysicalUV` uses the mip from the indirection texel (`ACoarserResidentPageIsAddressedAtItsOwnMip`). (c) `VTFeedbackAnalyzer::Analyze` inserts the 1x1 coarsest page first plus each wanted page's parent. Gate the VT branch on `IsReadyForShading()`. [Details](terrain-virtual-texturing-details.md#3-the-coarse-mip-fallback-is-the-whole-anti-pop-mechanism-and-it-has-three-parts)
3. **Publish indirection as a delta equal to the rebuild.** (a) An eviction is an explicit all-zero texel; `Invalidate()` and `GPUPagedCache::DeallocateObject` do not fire the eviction listener, so hand-write their unmaps before clearing `m_Resident`. (b) Re-propagate over the descendants of every change (`VTIndirectionDelta::GetFillRect`), mip-0-only changes included. (c) One entry per texel, last write wins. [Details](terrain-virtual-texturing-details.md#4-publishing-is-a-delta-and-three-things-keep-it-equal-to-the-rebuild)
4. **Treat a full rebuild outside its three triggers as a delta bug.** Triggers: first publish after `Configure()`, a delta that outgrew its upload buffer, `OLO_TERRAIN_VT_FULL_REBUILD`. Check the lever before reading `Stats::m_IndirectionFullRebuilds`; forcing the rebuild is the first test when terrain looks wrong. [Details](terrain-virtual-texturing-details.md#4-publishing-is-a-delta-and-three-things-keep-it-equal-to-the-rebuild)
5. **Do not replace the single fill bounding box with N rectangles without measuring the dispatch count.** Publish is dispatch-bound at current sizes. [Details](terrain-virtual-texturing-details.md#the-bounding-box-is-most-of-the-remaining-cost-and-that-is-the-measured-surprise)
6. **Keep the equivalence negative controls and the GPU check.** `TheEquivalenceCheckFailsWhenTheDeltaOmitsItsUnmaps` and `...WhenThePropagationStopsOneLevelShort` must keep rejecting a broken delta; the CPU model does not cover the kernels, so run `TerrainVirtualTextureVisualEvidenceTest.TheDeltaPublishesTheSameFrameAsTheFullRebuild` after kernel changes. [Details](terrain-virtual-texturing-details.md#the-bounding-box-is-most-of-the-remaining-cost-and-that-is-the-measured-surprise)
7. **Change `VTIndirectionHeader` in three places.** `TerrainVTIndirectionWrite.comp`, `TerrainVTIndirectionFill.comp` and the C++ struct share one std430 header on `SSBO_TERRAIN_VT`; a one-sided change misaligns `b_VTUpdates` silently. [Details](terrain-virtual-texturing-details.md#the-bounding-box-is-most-of-the-remaining-cost-and-that-is-the-measured-surprise)
8. **Keep the two `VTServicePageRequests` rules separate.** Pass 2's cap `min(bakeBudget, cacheTileCount - touchedThisFrame)` is the pin; pass 1's reverse order is retention only. After changing one, run the other's test. Record hits with `GPUPagedCache::Touch`, never `AllocatePages`. [Details](terrain-virtual-texturing-details.md#5-two-servicing-rules-and-only-one-of-them-is-the-pin)
9. **Keep bake and shade an exact inverse, border included.** Tile texel `j` is filled from page-local `(j + 0.5 - border) / pageTexels`. Only heightmap and splatmaps clamp to `[0,1]`; layer arrays tile. Never give the physical cache a mip chain. Pins: `PhysicalUVLandsInsideTheOwningTileInterior`, `BorderedRectExtendsThePageByExactlyTheBorderDensity`. [Details](terrain-virtual-texturing-details.md#6-the-bakeshade-coordinate-mapping-is-an-exact-inverse-including-the-border)
10. **Call `Invalidate()` for every input of a baked tile.** Inputs: height field, splatmaps, layer arrays, world transform. A new sculpt path writing the height field without the existing flags needs its own entry. Call `Update()` every frame even with missing inputs (it clears `IsReadyForShading()` and the feedback buffer). Compare matrices with the epsilon `MatricesDiffer`; the bake uses the ABSOLUTE model matrix and the fragment path re-adds `u_RenderOrigin` in `triplanarSample*`, so change neither half alone. [Details](terrain-virtual-texturing-details.md#7-things-that-invalidate-the-cache-and-are-easy-to-forget)
11. **Keep `Update()` in the terrain update pass, not a render-graph pass.** A `Setup()` branching on a runtime toggle is frozen by the fingerprint cache; read [virtual-shadow-map-page-cache.md](virtual-shadow-map-page-cache.md) §5. [Details](terrain-virtual-texturing-details.md#8-the-traps-around-it)
12. **Add no UBO binding.** Compute parameters live in a header at the front of each SSBO; shading parameters ride `UBO_TERRAIN`. [Details](terrain-virtual-texturing-details.md#8-the-traps-around-it)
13. **Treat a new `TEX_*` slot as a shader edit.** Update `HEAP_IMAGE_SLOT_BASE` and the offset table in `include/BindlessHeap.glsl` and the copy in `BindlessHeapGpuTest.cpp` (`BindlessShaderPipeline.HeapImageBaseMatchesTheBindingLayout`). [Details](terrain-virtual-texturing-details.md#8-the-traps-around-it)
14. **Bind through the `HeapBinding` seam, program first.** Plain `BindTexture` reads black on the bindless route; new raw `RenderCommand::BindTexture` / `BindImageTexture` sites fail `RHIBoundaryRatchet.RawGLOutsideTheBackendOnlyEverShrinks`. [Details](terrain-virtual-texturing-details.md#8-the-traps-around-it)
15. **Edit `TerrainParams` (binding 10) only in `include/TerrainParamsBlock.glsl`.** Share `TerrainLayerBlend.glsl` and `OLO_TERRAIN_TRIPLANAR_SLOPE` across forward, deferred and the bake; the sampling itself is deliberately not shared. [Details](terrain-virtual-texturing-details.md#8-the-traps-around-it)
16. **Keep adaptive images in atlas space.** Sector table: 64 entries in the `TerrainParams` UBO (`kVTMaxSectorsWide` 8, tied to `kTerrainVTMaxSectors` by `static_assert`, `MAX_COMMAND_SIZE` 4096). Keep buddy-aligned origins; clamp every lookup and request to the sector's `MaxMip`; derive coarsest mip from size via `MaxMip()`, never store it. [Details](terrain-virtual-texturing-details.md#9-the-adaptive-layer-slice-3--everything-is-still-atlas-space-and-that-is-the-design)
17. **Drive image sizes from feedback and resize by remap.** Feedback mip field stores `wantedMip + 1`; hysteresis counts analyses. Resize uses `VTRemapPageKey` + `GPUPagedCache::MoveObject`, never a rebake; a shrink's finest level goes via `DeallocateObject` (hand-write its unmap). Never call `VTDesiredImageSize` speculatively: pass the budget as `canResize`. [Details](terrain-virtual-texturing-details.md#9-the-adaptive-layer-slice-3--everything-is-still-atlas-space-and-that-is-the-design)
18. **Filter stale feedback at both gates and sort pins first.** Analyzer uses the launch-time sector snapshot; `ServiceRequests` re-filters against the live table. Persistent growth of `Stats::m_StaleFeedbackTexels` is an addressing bug. Sort by (pin, coarser mip, count, key) (`AOnePageImagesPinSortsBeforeEveryCameraRequest`). [Details](terrain-virtual-texturing-details.md#9-the-adaptive-layer-slice-3--everything-is-still-atlas-space-and-that-is-the-design)
19. **Respect the BC7 copy units.** `CopyImageSubDataRegion` width/height are source texels; destination offsets are cache texels, multiples of 4. `Sanitize()` rounds the border UP to even when compressed. `m_BakeList` keeps real cache coordinates. Shading is unchanged (`TheCompressedCacheCostsAQuarterAndKeepsTheSurface`). [Details](terrain-virtual-texturing-details.md#10-bc7-cache-tiles-slice-4--the-bake-is-unchanged-the-destination-moved)
20. **Keep streamed terrain on the splat path** (`!terrain.m_StreamingEnabled` in `Scene.cpp`); a floating-origin rebase invalidates the whole cache. [Details](terrain-virtual-texturing-details.md#11-what-slices-14-still-do-not-do)
