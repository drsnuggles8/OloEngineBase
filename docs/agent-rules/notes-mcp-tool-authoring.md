# Subsystem notes — authoring MCP tools for the editor

How to add an `olo_*` tool to the OloEditor MCP diagnostics server, and the traps that cost time. Server catalogue and attach flow: [../guides/mcp-diagnostics-server.md](../guides/mcp-diagnostics-server.md).

## Rules

1. **Split every tool in three: pure header, handler, unit test.** Pure `OloEditor/src/MCP/Mcp<Name>.h` (no renderer/httplib/`McpServer`; `InputSchema()`, `ParseArgs(...)`, `Apply(...)`); handler in `McpTools<Domain>.cpp` registered in `Register<Domain>Tools(AutomationRegistry&)` with `MainMarshaled = true`, gathering live facts inside `host.MarshalRead([...]{ ... })`; test `OloEngine/tests/MCP/Mcp<Name>Test.cpp` (`// OLO_TEST_LAYER: unit`, added to the explicit list in `tests/CMakeLists.txt`). All logic lives in the pure header. [Details](notes-mcp-tool-authoring-details.md#1-the-three-part-split-every-tool-follows)
2. **Take `IAutomationHost&` in a handler, not `McpServer&`** (#1123). Only `McpToolsGateway.cpp` tools close over the server. Registering a built-in resource, prompt or tool changes what headless tests see, so unrelated `resources/list` count assertions can fail. [Details](notes-mcp-tool-authoring-details.md#1-the-three-part-split-every-tool-follows)
3. **Set `AutomationCommand::Undo` on every new command.** `olo_transaction_apply` default-denies `Unspecified`. Values: `None`, `EditorUndoStack`, `Irreversible`, `HistoryControl`. `ProjectWrite = true` with `Undo::None` fails a census test; `MainMarshaled = false` commands are not batchable, which is correct. [Details](notes-mcp-tool-authoring-details.md#5b-declare-automationundo-or-your-command-is-silently-un-batchable-1127)
4. **Set `ToolDef::ProjectWrite = true` on every tool that mutates the project,** paired with `MutatingAnnotations(/*idempotent*/ false)`. It is the consent gate (`GetWriteConsentMode()` Disabled by default, never persisted) and the `oloctl` read-only gate. Camera, viewport and render overrides are not `ProjectWrite`. [Details](notes-mcp-tool-authoring-details.md#5-write-tools-consent-gate-undo-and-the-reflection-gap)
5. **Route writes through `CommandHistory` as a UUID-keyed `ComponentChangeCommand<T>`; skip the push (`changed=false`) when unchanged.** Specialize `PreferValueComparison<T>` (`OloEditor/src/Panels/SceneHierarchyPanel.cpp`) with an authored-fields-only `operator==` for types where `std::memcmp` is wrong (padding or runtime fields); never float `==`. Resolve scene and history inside `server.MarshalRead(...)`, returning `{"__error", msg}` on failure. [Details](notes-mcp-tool-authoring-details.md#5-write-tools-consent-gate-undo-and-the-reflection-gap)
6. **Pick one registry accessor for a writable field.** There is no runtime reflection (`OLO_PROPERTY()` expands to nothing). `MakeField` / `MakeFieldAccess` for public members, `MakeSetterField` for private Get/Set pairs ([mcp-setter-based-field-registry.md](mcp-setter-based-field-registry.md)), `MakeMapKeyField` for map-backed fields addressed by `field.key`. Names are the `m_`-stripped keys. [Details](notes-mcp-tool-authoring-details.md#5-write-tools-consent-gate-undo-and-the-reflection-gap)
7. **Do not expect a new tool in the default `tools/list`.** It is dispatchable immediately, but listing shows a profile. Use `OLO_MCP_TOOL_PROFILE=full` or the MCP Server panel radio; `olo_tool_search` is profile-blind. Tests asserting on `tools/list` call `server.SetExposurePolicy({ExposureProfile::Full, {}})` first. Adding to `CoreToolNames()` (`McpExposure.h`) is a budget decision; `McpExposureProfileTest` has a byte ceiling. [Details](notes-mcp-tool-authoring-details.md#1b-your-new-tool-will-not-appear-in-the-default-toolslist-1124)
8. **Choose Name and Toolset so the `oloctl` spelling is unique.** Group is the lowercased toolset (`_` and `.` become `-`), command is the name minus `olo` and repeated group segments. Never collide (`NoTwoProductionCommandsDeriveTheSameSpelling`); never name a toolset `help`, `version`, `catalogue`, `call` or `events`; avoid argument names equal to `oloctl` options (`--port`, `--url`, `--token`, `--timeout`, `--json`, `--structured`, `--compact`, `--verbose`, `--help`, `--version`, `--arguments-json`). [Details](notes-mcp-tool-authoring-details.md#1c-your-tools-name-and-toolset-decide-its-cli-spelling-1125)
9. **Build the `OloEditor` target too before calling a tool done.** A green `OloEngine-Tests` compiles and registers handlers but never runs them, and does not build the editor. Registration-only tests are safe headless (`McpOutputSchemaCoverageTest.cpp`). [Details](notes-mcp-tool-authoring-details.md#2-a-green-test-run-does-not-mean-your-handler-works)
10. **Author schemas with the `McpSchemaBuilder.h` DSL, never raw JSON literals.** Keep array element order, keep numeric bounds JSON integers (`Min/Max/ExclusiveMin/MinItems/MaxItems` take `i64`; assert `.dump()` too), and give an object only described by `.Desc()` no `properties` key. [Details](notes-mcp-tool-authoring-details.md#3-schemas-use-the-builder-dsl-and-mind-byte-identity)
11. **Declare entity ids as plain `string`, and treat `integer` as strict.** `EntityId()` is byte-locked by `McpSchemaBuilderTest.cpp`; `5.0` is rejected by design. Validation is `McpServer::ValidateArguments` returning `kInvalidParams (-32602)`; the 8 MiB cap is set in `McpServer::Start()`. [Details](notes-mcp-tool-authoring-details.md#validation-edges)
12. **Emit the top-level `title`; use `ReadOnlyAnnotations()` / `MutatingAnnotations()`.** Hint defaults: `readOnlyHint` false, `destructiveHint` true, `idempotentHint` false, `openWorldHint` true. [Details](notes-mcp-tool-authoring-details.md#4-tool-annotations-mcp-2025-06-18)
13. **Never nest `m_ConsentMutex` and `m_InFlightMutex`; keep the cancellation barrier.** `notifications/cancelled` sets the flag under `m_InFlightMutex`, takes a bare `lock_guard(m_ConsentMutex)` barrier, then `notify_all()` outside the lock. Register the in-flight `CancelFlag` before the consent gate; cancellation wins over Approve. [Details](notes-mcp-tool-authoring-details.md#6-consent-and-cancellation-concurrency-invariants)
14. **Never scan a narrow consecutive port window on Windows.** Stride derived ports by the prime 769 (wider than excluded blocks; inspect with `netsh interface ipv4 show excludedportrange protocol=tcp`); the explicit `basePort` path stays exact. [Details](notes-mcp-tool-authoring-details.md#7-dont-scan-a-narrow-consecutive-port-window-on-windows)
15. **Tag frame capture with `GetName()` and commit centrally.** Live names differ from class names (`ScenePass`, `FoliagePass`, `WaterPass`, `DecalPass`). `Renderer3D::EndScene` calls `FrameCaptureManager::CommitFrame()` after `RGraph->Execute()`; bucket passes call `BeginPass(GetName())` + `OnPreSort` at the top of Execute. `capturedPassCount == commandBucketPassCount` excludes culled passes. [Details](notes-mcp-tool-authoring-details.md#8-frame-capture-is-graph-wide-and-names-come-from-the-live-graph)
16. **Widen the `CapturedCommandData::IsDrawCommand()` whitelist rather than filtering per tool.** It omits `DrawTerrainPatch`, `DrawVoxelMesh`, `DrawDecal`, `DrawFoliageLayer`; `FrameCaptureStats.DrawCalls` has a different source. [Details](notes-mcp-tool-authoring-details.md#8-frame-capture-is-graph-wide-and-names-come-from-the-live-graph)
17. **Report unqueryable render state as unknown, and make "explain" tools a root-cause cascade.** Queryable: `Renderer3D::GetViewFrustum()` (radius expanded 1.3x before testing), local `TransformComponent::GetTransform()`. Not queryable: per-entity HZB occlusion and LOD pick. Scene meshes use the shared deferred PBR shader; a missing `MaterialComponent` is not an invisibility cause; there is no per-entity render layer. [Details](notes-mcp-tool-authoring-details.md#9-what-the-live-frame-can-and-cannot-honestly-answer)
18. **Verify a synthetic input's effect and refuse to report `ok` when it did not land.** `olo_input_inject` reports `after.cursorLanding`; the hardware cursor won the ImGui queue when the physical mouse was off the window. Run a controlled A/B on the environment before hunting stuck state. [Details](notes-mcp-tool-authoring-details.md#10b-a-synthetic-input-event-is-a-request-not-a-guarantee--measure-it-issue-854)
19. **Make `olo_render_toggle_pass` an ephemeral MCP-owned override layer, not a flipped `*Enabled`.** `GetPostProcessSettings()` is also persisted by `SaveScene`, `SaveSceneAs` and `AutoSaveScene`; needs multi-angle visual verification. [Details](notes-mcp-tool-authoring-details.md#11-why-olo_render_toggle_pass-is-still-deferred)
20. **Make new URI-bearing output survive redaction,** and bind `server.HandleMessage(...)` to a local before `FindToolEntry` (it dangles on a temporary). The drive-path regex corrupts `olo://` without the captured-prefix fix; `u8`/`u32`/`u64` are global typedefs. [Details](notes-mcp-tool-authoring-details.md#12-misc-traps)
21. **Convert tool outputs to `Structured(j)` with required fields only, never `.NoAdditional()` on outputs.** Image tools set `StructuredContent = meta`; free-form tools stay text-only with an exempt-list entry. [Details](notes-mcp-tool-authoring-details.md#12-misc-traps)
22. **Expect shader reload to report `reloadable` and failures as `status: "failed"`.** Only source-string shaders (boot, fallback, shader-graph) cannot reload; a malformed `#type` directive still asserts in `OpenGLShader::PreProcess`. [Details](notes-mcp-tool-authoring-details.md#10-two-former-tool-limitations-corrected-by-1357)
