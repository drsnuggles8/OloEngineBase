# C++ Coding Quality Rules

Applies to: `**/*.cpp`, `**/*.h`, `**/*.hpp`

Conventions that prevent common SonarQube findings and match the project's C++23 style. Rules are listed in the original section order so a citation by number (for example "§7", "§13") finds its rule; the details file has the code examples.

## Rules

1. **§1 — Declare a variable used only inside an `if`/`switch` in its init-statement.** `if (auto metallic = mat.GetMetallicFactor(); ImGui::DragFloat(...))`. Keep it in the outer scope if it is read after the `if`. [Details](cpp-coding-quality-details.md#1-if--switch-init-statements)
2. **§2a — Never use `==` / `!=` on `float`, `double`, `glm::vec*` or `glm::mat*`.** For tolerances use an epsilon (`std::abs(distance) > epsilon`); for bit-exact comparison (undo, round-trip) use `Math::BitwiseEqual` from `OloEngine/Math/Math.h`, not hand-written `std::memcmp`. For a whole trivially-copyable struct, `operator==` returns `Math::BitwiseEqual(*this, other)`. [Details](cpp-coding-quality-details.md#2a-never-use----directly-on-floats-or-float-containing-types)
3. **§2b — Validate every float from YAML, JSON, network or env config with `std::isfinite` before use.** This includes `Networking/Replication/ComponentReplicator.cpp` and `Task/Scheduler.cpp`. Reject non-finite values before any `static_cast<u32>` / `static_cast<i32>` (UB for NaN/inf, and `x < 0.0f` is false for NaN). Prefer a pure helper returning the sanitized value or `std::optional`. [Details](cpp-coding-quality-details.md#2b-validate-deserialized--external-floats)
4. **§3 — Use `auto` when the type is obvious from the right-hand side** (constructor, `static_cast`, factory); not when it hides a non-obvious type. [Details](cpp-coding-quality-details.md#3-use-auto-to-avoid-redundant-type-names)
5. **§4 — Hoist a loop bound that calls a method (`.size()`, `.Num()`) when the container is not modified in the loop.** Keep it inline if the loop erases or pushes. [Details](cpp-coding-quality-details.md#4-cache-loop-stop-conditions)
6. **§5 — Include what you use.** Do not rely on transitive includes for `<algorithm>`, `<cstring>`, `<cmath>`, `<limits>`, `<string>`, `<vector>`, `<functional>`; public headers and headers included from another target must be self-contained (the PCH covers `OloEngine/src/` only). [Details](cpp-coding-quality-details.md#5-include-what-you-use)
7. **§6 — Bounds-check the source range before `std::memcpy` or pointer arithmetic on a container.** Compute available elements and copy `std::min` of requested and available. [Details](cpp-coding-quality-details.md#6-bounds-check-before-raw-memory-operations)
8. **§7 — Write a defaulted comparison as `auto operator==(const T&) const -> bool = default;`.** MSVC rejects `auto operator==(...) const = default;` without the trailing return. For a member without `operator==` (e.g. `Material`), write it manually with `Math::BitwiseEqual`. [Details](cpp-coding-quality-details.md#7-defaulted-operator-msvc-quirk)
9. **§7 — Compare `UUID` members via `static_cast<u64>()` in a manual `operator==`.** `UUID`'s implicit `operator u64()` causes C2666 ambiguity with a member `operator==`. [Details](cpp-coding-quality-details.md#7-defaulted-operator-msvc-quirk)
10. **§7 — Exclude `mutable` runtime caches from `operator==` and opt the component into `PreferValueComparison<T> : std::true_type`.** A defaulted `==` includes the cache (e.g. `TransformComponent`, #442), and a render pass can repopulate it between the undo snapshot and the compare, so the whole-struct `memcmp` in `SceneHierarchyPanel::DrawComponent` sees false diffs; write a manual `operator==` over the authored fields. [Details](cpp-coding-quality-details.md#mutable-caches-must-be-excluded-from-operator-and-routed-off-the-memcmp-undo-path)
11. **§7 — Cache a computed result plus a bit-copy of its inputs when the inputs are public fields; do not use a setter dirty-flag.** Compare current inputs with `Math::BitwiseEqual` on read and seed `bool m_CacheValid = false`. [Details](cpp-coding-quality-details.md#prefer-input-snapshot-validation-over-a-setter-dirty-flag-when-the-inputs-are-public)
12. **§8 — Prefer structured bindings in `if`-init lookups and range-for.** `if (auto it = map.find(key); it != map.end()) { auto& [id, entry] = *it; }`. [Details](cpp-coding-quality-details.md#8-prefer-structured-bindings-and-range-for)
13. **§9 — Never allocate an ImGui widget per cell of a potentially large grid.** Use `ImGuiListClipper` for rows, derive visible columns from `ImGui::GetContentRegionAvail().x / per-widget-width`, and page or scroll beyond that. [Details](cpp-coding-quality-details.md#9-ui-widget-budget)
14. **§10 — Gate on C++ language version with `_MSVC_LANG` as well as `__cplusplus`.** This repo does not set `/Zc:__cplusplus`, so a bare `__cplusplus >= 202302L` is always false on MSVC and silently compiles the feature out. Use `(__cplusplus >= 202302L || (defined(_MSVC_LANG) && _MSVC_LANG >= 202302L))`. [Details](cpp-coding-quality-details.md#10-language-version-gates-check-_msvc_lang-not-bare-__cplusplus-msvc-quirk)
15. **§11 — Reset a raw GL handle published into global renderer state (`Renderer3D::Set*TextureID`) in `RenderPipeline::PrepareFrame`.** The render graph can cull the publishing pass, so clearing in its `Execute()` is not enough; a stale id gives `GL_INVALID_OPERATION ... not a valid texture name` every frame with correct-looking output (#505). Debug GL callback logs a `std::stacktrace` for the offending bind. [Details](cpp-coding-quality-details.md#11-raw-gl-handles-published-through-global-state-must-be-reset-per-frame)
16. **§12 — In a `ParallelFor` result-collecting lambda, assign the result's identifying field (e.g. `Stage`) before the `hasError` early-exit.** Otherwise a never-run task's default value reaches the collect loop and can crash a stage-to-string helper (#568). Audit every field the collect loop reads whenever changing from fail-first to report-every-failure. [Details](cpp-coding-quality-details.md#12-parallelfor-result-structs-populate-identifying-fields-before-the-early-exit-check-not-after)
17. **§13 — Name GPU-mirror struct fields in bare `PascalCase`, not `m_PascalCase`.** This applies to structs mirroring a GLSL uniform/buffer block (`UBOStructures::*UBO`, `VirtualClusterGpuRecord`, `InstanceData`, `ShaderDebugDrawLine`) so fields read one-for-one against the GLSL members (#870). [Details](cpp-coding-quality-details.md#13-gpu-mirror-struct-naming-bare-pascalcase-fields-padn-pads-never-a-leading-underscore)
18. **§13 — Name explicit padding `Pad0`, `Pad1`, ... in C++; never `_Pad0`, `_pad0`, `_padding0`.** `_Pad0` is reserved to the implementation in every scope. A pad array keeps a descriptive name (`i32 PadEntity[3];`). When sweeping, grep `_[A-Za-z_]*[Pp]ad`, since prefixed spellings (`_pbrPad2`, `_StatePad0`) hide the pad word mid-identifier. [Details](cpp-coding-quality-details.md#13-gpu-mirror-struct-naming-bare-pascalcase-fields-padn-pads-never-a-leading-underscore)
19. **§13 — Leave the GLSL side's leading-underscore pads (`_padding0`, `_foliagePad1`, `_camera_pad_view`) alone.** `ShaderUBOSizeConsistencyTest` treats `name.starts_with('_')` as a std140 parity pad, uniform-block members must match across stages, and non-instanced block members share global scope, hence per-block prefixes. GLSL text embedded in C++ (`ShaderBindingLayout::Get*Layout()` strings, `ShaderGraphCompiler` output) keeps the GLSL spelling. [Details](cpp-coding-quality-details.md#the-glsl-side-keeps-its-leading-underscore--do-not-fix-it)
