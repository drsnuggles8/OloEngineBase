# The OpenGL abstraction boundary — where it actually leaks, and how to measure it

Keeps GL and Vulkan types out of the neutral renderer (#691, ADR 0010/0011). Applies to: `Renderer/`, `Platform/OpenGL/`, `Platform/Vulkan/`.

## Rules

1. **Run `RHIBoundaryRatchetTest` for counts; never re-grep `glXxx(`.** [Details](rhi-abstraction-boundary-details.md#1-do-not-trust-a-glxxx-grep--three-published-numbers-none-of-them-right)
2. **Strip `GLenum`/`GLuint` from `RendererAPI` virtuals before deleting `glad/gl.h` includes.** Check transitive sources (PCH, Tracy, `Platform/<Backend>/` headers) and remove an include only with zero `GL*` identifiers, by compiling. [Details](rhi-abstraction-boundary-details.md#the-ordering-trap)
3. **Move backend knowledge (e.g. `GLClearProgramGuard`) into the backend; only `Create()` factory TUs include `Platform/<Backend>/`.** [Details](rhi-abstraction-boundary-details.md#a-platformbackend-include-leaks-just-as-much-and-this-scan-cannot-see-it-either)
4. **Histogram distinct entry points before a sweep, and grep `Renderer/RHI/` for the concept before adding vocabulary.** [Details](rhi-abstraction-boundary-details.md#2b-the-facade-was-not-just-gl-typed-it-was-incomplete--and-that-is-the-bigger-number)
5. **Relocate `Renderer/Debug/` GL code under `Platform/OpenGL/`, never exempt it; `GLStateGuard` must be inert off GL.** [Details](rhi-abstraction-boundary-details.md#3-rendererdebug-is-43-of-the-problem-and-is-not-exempt)
6. **Keep identity (`RHI::ResourceHandle`), shader offset (`RHI::HeapOffset`) and native handle separate; compare objects by `GetRHIHandle()`.** `facade_native_id_params` (0) is the completion criterion; `sweep_renderer_id` is only a ratchet. [Details](rhi-abstraction-boundary-details.md#4-one-u32-is-doing-three-jobs--do-not-replace-it-with-one-new-type)
7. **On a handle/`u32` compiler error, re-type the callee only if it merely carries the value;** otherwise convert at the caller (`handle.Index`, `Debug::NativeOf`). [Details](rhi-abstraction-boundary-details.md#the-compiler-tells-you-two-types-disagree-it-never-tells-you-which-side-is-wrong)
8. **No global regex renames in a currency migration: edit from the compiler's `(file, line)` output and read conditionals.** In tests `0` means `RHI::NullResource`, not `TestHandle(0)`. [Details](rhi-abstraction-boundary-details.md#a-global-rename-is-always-wrong-here-and-slice-6-proved-it-five-times)
9. **`Delete*` must resolve and unregister; grep `.data()` on any container whose element type changes.** [Details](rhi-abstraction-boundary-details.md#queries-become-identities-and-the-data-trap-was-real)
10. **Migrate one resource chain per commit and the command bind cache as one unit.** [Details](rhi-abstraction-boundary-details.md#the-migration-grain-is-a-resource-not-a-layer--and-migrating-one-is-the-only-way-to-find-the-missing-facade-surface)
11. **Move an import to `ImportTextureHandle` only if diagnostics can read it** (`Debug::NativeTextureIdForDiagnostics`, in `Renderer/Debug/`). [Details](rhi-abstraction-boundary-details.md#importtexturehandle-blinds-resolvetexture-and-resolvetexture-is-what-the-mcp-capture-endpoints-read)
12. **Set both `.TextureID` and `.Handle` wherever the graph assigns a texture (transient acquire, alias fan-out, `DeclareTransientTexture`); pass identity into `AllocateTextureHandle`'s change test.** [Details](rhi-abstraction-boundary-details.md#two-silent-defects-both-the-same-shape-both-found-by-reading-rather-than-by-a-test)
13. **Call `InvalidateTextureBinding` and `RHI::DescriptorHeap::InvalidateResource` wherever storage is recreated; key caches on `RHI::HashKey(handle)`.** [Details](rhi-abstraction-boundary-details.md#but-invalidation-gets-more-load-bearing-not-less--the-one-place-handles-are-weaker)
14. **Every texture type that mints an identity retires it (`Utils::RetireTextureViews`, `noexcept`).** [Details](rhi-abstraction-boundary-details.md#every-texture-type-that-mints-an-identity-owes-a-retire)
15. **Bindless GLSL uses the raw-GLSL route (`OLO_BINDLESS`); key the program-binary cache on the variant.** [Details](rhi-abstraction-boundary-details.md#the-raw-glsl-route-and-what-converting-a-real-pass-actually-cost)
16. **`FlushHeapOffsets()` at every converted pass, draw and ping-pong iteration; bind the shader first or use `PublishTextureOffsetAndBind`.** [Details](rhi-abstraction-boundary-details.md#publishing-the-heap-once-per-frame-is-wrong-and-the-test-was-hiding-it)
17. **Clear inputs with the reserved null descriptor (`RHI::kNullHeapOffset`), per kind.** [Details](rhi-abstraction-boundary-details.md#unbind-has-no-translation-so-the-heap-needs-a-reserved-null-descriptor)
18. **`SamplerDesc{}` means inherit the object's state; integer formats need `NEAREST`.** [Details](rhi-abstraction-boundary-details.md#samplerdesc-means-inherit-and-getting-there-took-two-goes)
19. **A green suite says nothing about bindless: run the editor with `OLO_RHI_BINDLESS=1`, confirm each conversion in the log, and grep tests that load a converted shader (math harnesses use `ScopedSlotBasedShaders`).** [Details](rhi-abstraction-boundary-details.md#the-editor-gate-found-what-5296-tests-could-not--and-the-suite-structurally-cannot)
20. **Never quote a live ON-vs-OFF A/B on an animated scene; cite fixed-camera goldens.** [Details](rhi-abstraction-boundary-details.md#the-live-on-vs-off-ab-is-not-an-instrument-on-an-animated-scene--stop-retaking-it)
21. **Keep `EveryShaderIsOnTheRouteOrExplicitlyExcluded` green; `sweep_bind_texture_sites` misses `Texture::Bind(slot)`.** [Details](rhi-abstraction-boundary-details.md#done-needs-an-end-condition-and-it-has-to-be-a-test)
22. **Do not bump `shaderc_env_version_vulkan_1_2` in place; encode the target env in the SPIR-V cache filenameand pin `SetTargetSpirv`.** [Details](rhi-abstraction-boundary-details.md#6-the-shader-pipeline-is-a-genuine-head-start--and-has-exactly-one-trap)
23. **Vulkan hot reload is shader-to-N-pipelines: recreate lazily, destroy via `VulkanDeferredReclaim`.** [Details](rhi-abstraction-boundary-details.md#hot-reload-has-a-different-invalidation-granularity-per-backend)
24. **Call `RendererAPI::SetAPI` via `SelectRendererBackend` before `Window::Create`; `.github/workflows/vulkan-off.yml` builds the `OLO_WITH_VULKAN=OFF` path.** [Details](rhi-abstraction-boundary-details.md#7-backend-selection-startup-time-not-live--and-the-ordering-contract-is-already-load-bearing)
25. **Ratchet tests need floor assertions, must fail when a counter improves, and must scan blanked text (digit separators are not char literals).** [Details](rhi-abstraction-boundary-details.md#8-writing-a-ratchet-test-that-cannot-silently-pass)
26. **Enumerate facade sentinels (`DrawIndexed` 0 = all, `RHI::NoAttachment`, null handle, `SamplerDesc{}`), per-shader binding collisions, and GL's implicit sync (attachment layouts, mid-pass visibility, per-attachment aspect) before calling a port done.** [Details](rhi-abstraction-boundary-details.md#9b-the-facades-semantics-are-wider-than-its-signatures)
27. **Enable Vulkan features from `vkGetPhysicalDeviceFeatures2`: probe, enable (core-promoted ones default OFF), check the loaded entry point, fold promoted structs into the aggregate.** [Details](rhi-abstraction-boundary-details.md#the-three-questions-a-promoted-feature-still-owes-you)
28. **Vendored Vulkan headers precede `${Vulkan_INCLUDE_DIRS}`; never link `Vulkan::Vulkan` with volk (`/FORCE:MULTIPLE` makes it a runtime AV).** [Details](rhi-abstraction-boundary-details.md#vendored-headers-must-out-rank-the-installed-sdks--three-traps-all-hit)
29. **Production must tick every generation-counted queue (`VulkanDeferredReclaim::NotifyFrameCompleted()`), not only the test fixture.** [Details](rhi-abstraction-boundary-details.md#a-reclaim-queue-nobody-drains-leaks-with-green-tests)
30. **Vulkan compute takes no bare `uniform`s; bind every declared binding; name the resource kind in descriptor mappings; fixtures enable `SetTransientMaterializationEnabled` and pass `m_Enabled`.** [Details](rhi-abstraction-boundary-details.md#bare-uniforms-cannot-enter-spir-v-and-the-no-op-setter-makes-the-failure-silent)
31. **Verify orientation in a real window. A deferred clear carries requester identity and values; one-shot submits precede the recording frame (probe with `dynamic_cast`, not `GetAPI()`).** [Details](rhi-abstraction-boundary-details.md#a-deferred-clear-must-remember-who-asked)
32. **Set tessellation domain origin for GL-authored TES; never leave a draw with a null root address or a dangling UBO.** [Details](rhi-abstraction-boundary-details.md#the-water-murk-hunt-ended-at-the-tessellation-domain-origin)
33. **Do not gate on native GL names or stale framebuffer specs; audit upload size against shader indexing per draw site.** [Details](rhi-abstraction-boundary-details.md#two-stacked-shadow-bugs-split-by-a-live-mcp-ab)
34. **Use one predicate per global convention (`RHI::RenderTargetRowsAreBottomUp()`); re-run a reproduction before saying "fixed".** [Details](rhi-abstraction-boundary-details.md#13c-one-predicate-one-owner)
35. **Diagnostics: use `ResourceRegistry::Snapshot()`, never `Native != 0` or a `u32` truncation (`Debug::HasLiveTextureStorage`), name causes only if excludable.** [Details](rhi-abstraction-boundary-details.md#15b-native--0-is-not-a-liveness-test-and-the-exceptions-are-the-interesting-resources)
36. **Barrier `oldLayout` for one-shots comes from `CurrentExecutedLayout`; gate layout writes on `VulkanOneShot::Outcome`; widen source scope from the tracked layout; a faster path must rest the image where the first did; disable culling in fullscreen and billboard draws.** [Details](rhi-abstraction-boundary-details.md#16-a-cpu-side-layout-tracker-has-two-timelines-800-and-only-one-of-them-is-the-queues)
