# A GL global setter is the indexed setter for every draw buffer — porting it as "the fallback" is a permanent leak

Postmortem of issue #823 (and #896): read this before adding or changing a per-attachment render-state entry point on a `RendererAPI` backend (colour mask, blend enable, blend func, viewport, scissor).

## Rules

1. **Make a backend's global setter overwrite its whole per-attachment array.** In GL `glColorMask`, `glEnable`/`glDisable(GL_BLEND)` and `glBlendFunc`/`glBlendFuncSeparate` are defined as the indexed form applied to every draw buffer. Modelling it as "per-attachment value, falling back to the global" makes one indexed call permanent for the process. [Details](gl-global-setter-resets-indexed-state-details.md#the-rule-gl-encodes-and-the-half-that-gets-ported)
2. **Read the caller's comment when porting a facade entry point.** `CommandDispatch::ApplyRenderState` calls the global setter and only ever disables masked-out attachments, relying on the global call to have re-enabled the rest; the contract is stated there, not in the signature. [Details](gl-global-setter-resets-indexed-state-details.md#why-it-stayed-invisible-for-a-whole-phase)
3. **Treat the per-attachment array as the sole authority for colour mask.** `SetColorMask` fills `AttachmentColorMask` and the pipeline lowering reads only that array, with no `& globalMask` composed on top, so a `glColorMaski` widen survives a global narrow. [Details](gl-global-setter-resets-indexed-state-details.md#the-fix-and-its-shape)
4. **Do not assume "same archetype" means the same fix; run the suite covering the caller.** Making `SetBlendState` overwrite `AttachmentBlend` broke `DecalRenderPass`, which enables RT2 per-attachment with a global `blendEnabled = false`. [Details](gl-global-setter-resets-indexed-state-details.md#the-fix-and-its-shape)
5. **Model per-attachment blend as three states: `Inherit`, `ForceOn`, `ForceOff`.** A bool that can only OR cannot say "off" (`OITResolveRenderPass` disables on RT1 and RT2 never reached the pipeline on Vulkan). Both backends implement this rule; GL re-asserts standing opinions after the global `SetBlendState` via `ReassertAttachmentBlendOpinions`. [Details](gl-global-setter-resets-indexed-state-details.md#what-the-blend-twin-turned-out-to-need-a-third-state-896)
6. **Withdraw a per-attachment opinion with `ResetBlendStateForAttachment`, never by passing `false`.** `false` is a standing disable, which on attachment 0 kills blending for the process. Every pass that states an opinion must withdraw it: `OITResolveRenderPass`, `DecalRenderPass` (both paths), `ParticleRenderPass` (both paths). [Details](gl-global-setter-resets-indexed-state-details.md#what-the-blend-twin-turned-out-to-need-a-third-state-896)
7. **Never read `glIsEnabled(GL_BLEND)` to decide a withdrawal; keep a mirror and query `glIsEnabledi`.** The call reports index 0 only (and NVIDIA RTX 4090 returned `GL_TRUE` after `glEnablei(GL_BLEND, 1)`). A raw `GL_BLEND` flip that bypasses the class stales the mirror; `Init()` goes through `SetBlendState`, `GLStateGuard` does not restore per-attachment blend. [Details](gl-global-setter-resets-indexed-state-details.md#glisenabledgl_blend-does-not-report-index-0--dont-withdraw-from-it)
8. **Test per-attachment state through one recording, with a control.** `VulkanDrawPath.GlobalColorMaskResetsPerAttachmentDivergence` and `VulkanDrawPath.PerAttachmentBlendOpinionOutranksTheGlobalEnable` use a single recording because the state is process-scoped; the indexed-mask-really-masks assertion is the control. On GL use `GLAttachmentBlendOpinion.OpinionOutranksTheGlobalEnableAndWithdrawalRestoresIt` with `glIsEnabledi`. [Details](gl-global-setter-resets-indexed-state-details.md#what-the-blend-twin-turned-out-to-need-a-third-state-896)
9. **Do not verify a per-draw contract through a dispatch the production path does not use.** `VulkanPassSuite.DecalGBufferModeMatrixMasksItsTargetRenderTargets` substitutes `FixtureDecalDispatch`, so it misses that `DecalRenderPass::ExecuteOnGBuffer` channel masks are wiped by the global `SetColorMask` in `ApplyPODRenderState` after `InvalidateRenderStateCache()`; `PODRenderState::colorAttachmentWriteMask` is one bit per attachment and cannot express channel masks. [Details](gl-global-setter-resets-indexed-state-details.md#what-this-surfaced-next-door-and-did-not-fix)
10. **Preserve every indexed viewport rectangle and scissor rectangle/enable when a raw probe promises exact restoration.** Legacy `glViewport`, `glScissor`, `glEnable`/`glDisable(GL_SCISSOR_TEST)` overwrite them all; query with `glGetFloati_v` (viewports, can be fractional) and `glGetIntegeri_v` (scissors). [Details](gl-global-setter-resets-indexed-state-details.md#viewport-and-scissor-arrays-in-raw-probes)
11. **Construct a probe's indexed-state guard before the core `GLStateGuard`.** `GLStateGuard::Policy::Restore` restores global viewport/scissor, so reverse destruction must restore the individual slots after it; `GroomShellSpikeGpuContract.IndexedStateAndRangedBindingsSurviveTheProbe` pins this. [Details](gl-global-setter-resets-indexed-state-details.md#viewport-and-scissor-arrays-in-raw-probes)
12. **Verify a deferred-path suspect by hash A/B with a forward control in the same session, and check capture liveness.** Assert `ticking` / `stale` / `frameIndex` on every `olo_render_capture_target` / `olo_screenshot` (a minimised window gives identical images); see live-verification-noise-floor.md. [Details](gl-global-setter-resets-indexed-state-details.md#the-measurement-that-settled-it)
13. **Decode capture PNGs (unique values per channel) instead of eyeballing them.** `GBufferAlbedo` displayed white because alpha (metallic) is 0; a table containing a channel you already trust (RT0, `SceneDepth`) answers whether the instrument is lying. [Details](gl-global-setter-resets-indexed-state-details.md#the-measurement-that-settled-it)
14. **Prove a debug lever acts before concluding from its silence.** The overdraw view and tonemap exposure moved the frame and returned to the baseline hash (render-graph-transient-aliasing.md). [Details](gl-global-setter-resets-indexed-state-details.md#the-measurement-that-settled-it)
15. **Ask which attachments a wrong answer is visible on.** Every forward path displays render target 0 only, so a defect in attachments above 0 passes screenshot gates; the deferred path (G-Buffer RT1..3, `ComputeDeferredLit` unlit flag from `emissiveFlags.a > 0.5`) is where it shows. [Details](gl-global-setter-resets-indexed-state-details.md#the-checklist-for-the-next-facade-entry-point)
16. **For a new facade entry point, check whether its GL entry has an indexed sibling.** Decide whether it overwrites the indexed state and record the decision at the array's declaration. [Details](gl-global-setter-resets-indexed-state-details.md#the-checklist-for-the-next-facade-entry-point)
