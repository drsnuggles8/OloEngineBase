# Which declarations may index the descriptor heap, and which may not

Covers when a shader may use `GL_EXT_descriptor_heap` instead of classic `layout(binding = N)`: ADR 0011 amendments (95), (96) (issue #805) and (97). Read before converting any texture declaration or touching the material heap arm.

## Rules

1. **Index the heap only in two cases: a shader with no OpenGL twin, or the five material-local maps of a shader that has one.** A shader already needing `GL_EXT_ray_query` may reach any texture (amendment (95)); a shader with a GL twin may convert only albedo, metallic-roughness, normal, AO and emissive, and only on its Vulkan arm (amendment (96)). Everything else keeps classic `layout(binding = N)` on both backends. [Details](vulkan-shader-heap-indexing-details.md#which-declarations-may-index-the-descriptor-heap-and-which-may-not)
2. **Put the `#extension` directives at the shader's top.** GLSL needs every `#extension` before all other tokens; an include mid-file cannot do it. Use `#extension GL_EXT_descriptor_heap : require` and `GL_EXT_nonuniform_qualifier`, then `#include "include/DescriptorHeapTextures.glsl"` and `oloHeapSampleLod`. [Details](vulkan-shader-heap-indexing-details.md#2-what-must-hold)
3. **Guard a material arm's directives with `#ifdef OLO_VULKAN` and define `OLO_MATERIAL_VULKAN_HEAP_READER 1`.** `#ifdef` is not a token, so it stays legal and hides the directives from the GL tier. The token is read by `PBRCommon.glsl` and by `VulkanShader`. [Details](vulkan-shader-heap-indexing-details.md#how-a-material-shader-takes-the-arm)
4. **Never gate the declarations behind an `#ifdef` to make an older toolchain build.** `GL_EXT_descriptor_heap` needs Vulkan SDK 1.4.357.0 or newer; below that, configure refuses by name and the Vulkan shader tiers refuse per shader. The CI pin is in `.github/actions/setup-vulkan/action.yml`. See also `glsl-shaders.md` §1a and amendment (97). [Details](vulkan-shader-heap-indexing-details.md#2-what-must-hold)
5. **Write the GLSL as `layout(descriptor_heap) uniform texture2D name[]` with `descriptor_stride = 1`.** `resourceHeapEXT` built-ins and `layout(resource_heap)` do not exist and fail as undeclared identifiers. The index is a byte offset. [Details](vulkan-shader-heap-indexing-details.md#3-what-bit)
6. **Get offsets from the CPU resolvers.** `HeapBinding::ResolveShaderHeapTexture(handle)` and `ResolveShaderHeapSampler(desc)` (`HeapBindingSeam.h`); OpenGL answers `Invalid`, and a consumer shades untextured and counts it (`GpuPathTracerStats::TexturesAvailable`). The resolvers fork on the backend, not on `OLO_RHI_BINDLESS`. [Details](vulkan-shader-heap-indexing-details.md#1-how-a-shader-reaches-a-texture)
7. **Publish a changed `MaterialTextureTable` or `EmissiveTriangleTable` through a fresh `StorageBuffer`, never `SetData` into one a submitted frame may read.** Dropping the old `Ref` hands it to deferred reclaim for `kFramesInFlight` frames; the table is uploaded by device address (`StorageBuffer::kNoBinding`). See [gpu-path-tracer.md](gpu-path-tracer.md). [Details](vulkan-shader-heap-indexing-details.md#1-how-a-shader-reaches-a-texture)
8. **Resolve only textures at rest.** The resolver builds a whole-image view at `SHADER_READ_ONLY_OPTIMAL`; a render target cannot be resolved, which is why the environment cubemap and the IBL trio stay classic. [Details](vulkan-shader-heap-indexing-details.md#2-what-must-hold)
9. **Confirm masked materials per candidate.** `RayTracingScene` builds `Masked` instances with `FORCE_NO_OPAQUE`; the shader traces with `gl_RayFlagsNoneEXT` and calls `oloRayTracingConfirmCandidate` from `RayTracingAlphaTest.glsl`, defining `OLO_RT_SAMPLE_ALPHA` first. Without textures it traces opaque and counts `MaskedGeometryTracedAsSolid`. [Details](vulkan-shader-heap-indexing-details.md#2-what-must-hold)
10. **Do not expect reflection to see heap arrays.** SPIRV-Cross reports no resource for them, so the pipeline builder's mapping needs nothing; the heap is already bound per recording (`VulkanRendererAPI::PrepareDraw`). Sampler state comes from `VulkanSamplerHeap::CreateInfoFromDesc` (the integer-format `NEAREST` override stays with the draw path). [Details](vulkan-shader-heap-indexing-details.md#2-what-must-hold)
11. **Check device features when using `nonuniformEXT`.** Needs `descriptorHeap`, `shaderUntypedPointers` and `shaderSampledImageArrayNonUniformIndexing`; a missing last one fails as VUID-08740 at `vkCreateShaderModule`, not a compile error. Do not use descriptor-multiple indices: region offsets are not multiples of the descriptor size. [Details](vulkan-shader-heap-indexing-details.md#3-what-bit)
12. **Convert on Vulkan per declaration, never assume GL can.** A heap array has no `Binding`/`DescriptorSet` decoration, so partial conversion is legal on Vulkan; GL bindless is per PROGRAM (`Shader::IsBoundProgramBindless()`), so one unconverted sampler reads black. [Details](vulkan-shader-heap-indexing-details.md#4-the-material-arm-amendment-96--what-makes-a-partial-conversion-legal)
13. **Do not pass a combined sampler through a function call on the heap arm.** `sampler2D(texture2D, sampler)` must appear at point of use; use `PBRCommon.glsl`'s `OLO_MAT_*` macros, which inline `texture()` only on the Vulkan arm. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
14. **Give every lane a real descriptor.** An out-of-range heap index is undefined behaviour; "no map" and "could not resolve" both get `HeapBinding::ResolveShaderHeapNullTexture()`. The `Use*Map` gate is not enough because `PBR_GBuffer` takes it from the GPU Scene record. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
15. **Do not memoise heap offsets.** The slot cache keys on `VkImage` and an in-place reload keeps its `RHI::ResourceHandle`. `HeapBinding::ShaderHeapGeneration()` moves on slot reassignment, and `CommandDispatch`'s material-UBO cache key carries it with the heap epoch. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
16. **Treat a sampler offset as a second index.** One lane (`HeapOffsets[2].w`) serves all five maps because every material 2D descriptor uses `HeapBinding::MaterialTexture2DSampler()`; on GL it stays null. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
17. **State the arm opt-in once per entry point, and make every entry point sharing a stage body agree.** `VirtualMeshGBuffer.glsl` and `VirtualMeshletGBuffer.glsl` each `#define` the token for `include/VirtualGBufferFragment.glsl`; `VulkanShader` reads the entry shader's PRE-INCLUDE text, and `Shader::ReadsMaterialHeapOffsets()` is a process-wide flag written by the last `Bind`. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
18. **Keep the three `BindlessShaderPipeline` tests green.** `VulkanMaterialHeapArmLeavesNoMaterialLocalSamplerDeclared`, `EntryShadersSharingAMaterialStageBodyAgreeOnTheHeapArm`, `TheMaterialHeapArmCoversExactlyTheRecordedFamilies`; losing a `#define` is silent because the shader falls back to classic bindings. [Details](vulkan-shader-heap-indexing-details.md#what-bit-or-would-have)
19. **Restart the editor between A/B arms; `olo_shader_reload` does not rebuild a Vulkan GRAPHICS pipeline.** It returns `"ok": true, "status": "ready"` and the frame is unchanged. [Details](vulkan-shader-heap-indexing-details.md#proving-it-in-a-frame-restart-the-editor-do-not-hot-reload)
20. **A/B against git, not a hand-disabled arm.** Run `git checkout <base> -- OloEditor/assets/shaders/` for the baseline; commenting out `OLO_MATERIAL_VULKAN_HEAP_READER` is neither arm and textures surfaces wrongly. The C++ is inert without the token, so no rebuild. [Details](vulkan-shader-heap-indexing-details.md#proving-it-in-a-frame-restart-the-editor-do-not-hot-reload)
