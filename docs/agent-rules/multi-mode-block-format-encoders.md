# Validate a multi-mode block format one mode at a time, against the decoder's own read order

Applies to: `OloEngine/src/OloEngine/Renderer/BC6HEncoder.cpp`, `OloEditor/assets/shaders/include/BC6HEncodeCommon.glsl`, and any encoder for a block format with more than one block layout (BC7 has eight, ASTC more). A misplaced field in one mode corrupts only the blocks that chose it, so aggregate quality tests stay green (issue #624).

## Rules

1. **Derive per-mode field tables mechanically from the reference decoder's read sequence.** Use bcdec's `bcdec_bc6h_half()` switch; store `{slot, shift, bits, reversed}` per field as data walked by one packer. Keep the generator committed: `tools/bc6h/generate_cpp_mode_tables.py`. [Details](multi-mode-block-format-encoders-details.md#1-generate-the-field-tables-from-the-reference-decoder-then-prove-the-inverse-per-mode)
2. **Prove the inverse per mode, bit-for-bit, against the reference decoder.** `BC6H::EncodeBlockForModeForTest` returns the 48 half-floats the encoder predicts; `BC6HModeCoverageTest` decodes the same bytes with bcdec and requires exact float-bit equality. Never decode with your own decoder, and a PSNR tolerance proves almost nothing (a one-bit shift in a smooth block stays inside 35 dB). [Details](multi-mode-block-format-encoders-details.md#1-generate-the-field-tables-from-the-reference-decoder-then-prove-the-inverse-per-mode)
3. **Re-derive the mode field from the packed bytes independently.** `BC6HBlockModeReader.h` catches "encoded mode 7 as mode 6", which decodes cleanly as something else. [Details](multi-mode-block-format-encoders-details.md#1-generate-the-field-tables-from-the-reference-decoder-then-prove-the-inverse-per-mode)
4. **Pick test data for what the format finds hard, not what looks hard.** BC6H interpolates in half-float bit space (roughly logarithmic), so a 100:1 contrast block needs only about 1.6:1 endpoint range; two-subset modes bought 0.00 dB on a two-cluster image (`BC6HQuality.TwoClusterBlocksSurviveASingleEndpointPair`). Flat blocks win with mode 13 (16-bit base endpoint, +21.9 dB), smooth gradients with modes 0, 2, 5 (curvature), wide dynamic range with 13, 11, 12 (endpoint precision). Measure per block class, not in aggregate. [Details](multi-mode-block-format-encoders-details.md#2-the-interpolation-space-is-half-float-bits-not-radiance--so-high-contrast-is-not-the-hard-case)
5. **Satisfy the anchor-index constraint at fit time.** Orient endpoints in `FitEndpoints` (`anchorTexel`) so the extreme nearest the anchor texel's projection is endpoint 0, and restrict the anchor's index search to the legal lower half; swapping endpoints after quantizing breaks delta modes because endpoint 0 is their base. [Details](multi-mode-block-format-encoders-details.md#3-satisfy-the-anchor-index-constraint-when-you-fit-endpoints-not-after-you-quantize)
6. **Clamp a delta mode's endpoints into the storable window and let it compete.** Score every candidate on the error a conformant decoder would produce so an unrepresentable mode loses, with no fragile representability predicate. [Details](multi-mode-block-format-encoders-details.md#3-satisfy-the-anchor-index-constraint-when-you-fit-endpoints-not-after-you-quantize)
7. **Generate the GLSL tables from the C++ encoder, not from the spec again.** `tools/bc6h/generate_glsl_tables.py` reads `BC6HEncoder.cpp`. [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
8. **Port the integer half exactly; let only the fit differ.** Quantization, interpolation, index selection and packing translate one-for-one; PCA and least-squares refit are `double` on CPU and `float` in GLSL (99.6% unsigned / 99.2% signed blocks bit-identical). [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
9. **Test the GPU encoder as "not the worse path", not bit-equality.** `BC6HGpuEncoderTest` decodes both through bcdec and requires the GPU within 0.5 dB of the CPU. [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
10. **Avoid GLSL traps.** `partition` is a reserved word (the error shows on the next line as an unbalanced paren). `OLO_HEAP_IMAGE` cannot declare a `readonly` image; keep a read-only input on the slot path and use `OLO_HEAP_IMAGE_RW` under bindless as `Ocean_Assemble.comp` does. `glslc -DOLO_BINDLESS` rejects that macro on every shader, so A/B against an existing one first. [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
11. **Marshal worker-thread encodes to the context thread through the existing drain.** `AssetPackBuilder` runs on a worker; the encoder queues the job, enqueues a `FNamedThreadManager` task that drains it, and blocks. Add no pump; tests play the game thread by calling the drain (`BC6HGpuEncoder.AWorkerThreadsEncodeIsMarshalledToTheContextThread`). Bound the wait, latch off on the first timeout (the cook finishes on the CPU), and make the job own its input. [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
12. **Return bulk compute output in an image to save binding numbers.** UBO 65 is the last free UBO and the SSBO namespace is full; one `rgba32ui` texel is one 16-byte BC block, and signedness is a second shader variant rather than a parameter. [Details](multi-mode-block-format-encoders-details.md#4-porting-the-encoder-to-a-compute-shader-keep-the-integer-half-identical-and-return-the-result-in-an-image)
13. **Narrow a texture's format only on a measured condition with an invisible substitution.** `TextureCompression::AnalyzeChannels` reports whether R, G, B are equal at every texel and whether alpha leaves 255; greyscale narrows to BC4 with a swizzle `(R,R,R,1)`, matching BC7 output and `DecodeToRGBA8`. [Details](multi-mode-block-format-encoders-details.md#5-narrow-a-textures-format-only-on-a-measurement-that-proves-nothing-is-lost)
14. **Never narrow RGB with constant blue to BC5 automatically.** BC5 decodes blue as 0; it stays an explicit `.oloimport` choice and a test pins the refusal. Compute `HasAlpha` from alpha actually leaving 255, not `channels == 4`. [Details](multi-mode-block-format-encoders-details.md#5-narrow-a-textures-format-only-on-a-measurement-that-proves-nothing-is-lost)
15. **Keep the previous encoder's mode in the candidate set.** #624 still evaluates mode 10 (the only mode #440 emitted), so "no block got worse" is a property of the algorithm. [Details](multi-mode-block-format-encoders-details.md#validate-a-multi-mode-block-format-one-mode-at-a-time-against-the-decoders-own-read-order)
