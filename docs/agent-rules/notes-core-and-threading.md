# Subsystem notes — core types, C++ traps, task system, threading

Gotchas from `Core/`, `Templates/`, `Task/`, `Memory/` and untrusted-input hardening. Read before touching those directories or adding an environment read, cvar, atomic or multithreaded test.

## Rules

1. **Guard every float read from YAML/JSON with `std::isfinite` after `.as<f32>()` / `std::stof()`.** yaml-cpp decodes `.nan`/`.inf` successfully, so the default never applies. A test of the guard must put `.nan`/`.inf` in the YAML, not `"notanumber"`. [Details](notes-core-and-threading-details.md#1-asf32default-returns-nan--the-default-does-not-protect-you)
2. **Sanitize wire floats on the load path only (`if (ar.IsLoading())`) with `SanitizeWireFloat` / `SanitizeWireVec3`.** Fallbacks: translation/rotation 0, scale 1, mass 1 and `>= 0`. Keep the `ar <<` call order and float count unchanged (`kTransformBytes`). Reject non-finite in `SnapshotInterpolator::SetRenderDelay` and at the `u32` cast, since every NaN comparison is false. [Details](notes-core-and-threading-details.md#2-hardening-untrusted-float-boundaries)
3. **Parse env-var floats in a pure function returning `std::optional<f32>`, with `std::strtof`, never `std::atof`.** Reject `endPtr == env`, non-finite and out-of-range; `atof` is flagged by Sonar `cpp:S989`; `from_chars` for floats is missing on libc++. [Details](notes-core-and-threading-details.md#2-hardening-untrusted-float-boundaries)
4. **Take `Ref<T>` by value (or non-const reference) when calling any non-const method.** `const Ref<T>&` yields `const T*` (MSVC C2662). [Details](notes-core-and-threading-details.md#3-reft-is-const-propagating)
5. **Never pass a `Ref<ComputeShader>` through a `Ref<Shader>` API.** They are unrelated siblings of `RendererResource`; use a per-type command (`CreateComputeShaderCommand`). `ComputeShader::CreateFromFileAsync(path, onReady)` is opt-in; the 15+ existing compute systems load synchronously and hard-bail on a null shader. [Details](notes-core-and-threading-details.md#4-computeshader-is-not-a-shader)
6. **Never `delete this` (or delete the task) in a fire-and-forget `FTask` body.** `~FTask()` asserts `IsCompleted()`, set only after the runnable returns. Capture `LowLevelTasks::TDeleter` by value in the runnable. A non-`Application` test binary starts the scheduler the `FunctionalTest` way: `InitGameThreadId()`, `FNamedThreadManager::Get().AttachToThread(GameThread)`, `StartWorkers()`, no `StopWorkers`. [Details](notes-core-and-threading-details.md#5-a-fire-and-forget-ftask-must-never-delete-this-in-its-own-body)
7. **In the standby-worker code, wake nodes by atomically changing the shared head, and read `Node->Next` before `Trigger()`.** Drain with `m_StandbyState.exchange(StackMask)`, never an in-place walk (`FWaitingQueue::StartShutdown`, issue #359). Stress with `scripts/repro-flaky-test.ps1` (`OLO_TASK_GRAPH_NUM_WORKERS=4`, 2-core affinity, high `--gtest_repeat`). [Details](notes-core-and-threading-details.md#6-scheduler-shutdown-vs-standby-workers-is-the-recurring-race-class)
8. **Debug a scheduler hang in teardown with a Debug build and memory inspection.** `[ OK ]` followed by silence, no task-worker threads in the dump and main spinning in `SetEvent` means teardown; Release stacks are misreported by ICF. [Details](notes-core-and-threading-details.md#debugging-signature-for-a-scheduler-hang)
9. **Test `TLockFreeAllocOnceIndexedAllocator` through the singleton `FLockFreeLinkPolicy::s_LinkAllocator`, not a local instance,** which leaks pages under LSan. The only clean TSan test is concurrent `Alloc` first-touching the same page, not producer/consumer content reads. [Details](notes-core-and-threading-details.md#7-the-lock-free-allocator-two-testing-traps)
10. **Use `OLO_CORE_VERIFY`, not `OLO_CORE_ASSERT`, for a startup invariant.** `ASSERT` compiles out outside Debug (`OLO_ENABLE_ASSERTS`). Unit-test a pure validator (e.g. `McpServer::IsValidToolName`) for rejection instead of driving the asserting function. [Details](notes-core-and-threading-details.md#8-olo_core_verify-not-olo_core_assert-for-a-startup-invariant)
11. **Write `u8 u16 u32 u64 i8 i16 i32 i64 f32 f64 sizet uptr iptr` unqualified.** They are global (`Core/Base.h`); `OloEngine::u8` is a compile error. Real engine types still need the namespace. [Details](notes-core-and-threading-details.md#9-the-primitive-typedefs-are-at-global-scope-not-in-namespace-oloengine)
12. **Include the header that declares any name used unqualified inside a template.** A missing include (`Swap` from `Templates/UnrealTemplate.h`) hides until a new TU hits a deep `C3861`; suspect it when an error is unrelated to your change. [Details](notes-core-and-threading-details.md#10-an-unqualified-name-in-a-template-needs-its-own-include)
13. **In codegen-mirror tests, access the field as `holder.Field`, never via a bare reference parameter.** `decltype` of a reference id-expression yields the reference type (cascading C2651/C2039/C3312). [Details](notes-core-and-threading-details.md#11-codegen-mirror-tests-need-a-holder-struct-not-a-reference-parameter)
14. **Check for "Ported from UE5.x" notes and cross-file comments before deleting an unused type in UE-ported headers.** Keep `FRefCountedObject` ("KEPT FOR UE5.7 PARITY") and the `ENamedThread::RenderThread` scaffold; `EnqueueRenderThreadTask` is a compile error on purpose. [Details](notes-core-and-threading-details.md#12-two-unused-things-in-the-ue-ported-headers-are-kept-on-purpose)
15. **Do not make the gameplay RNG cryptographic or hide its seed.** `RandomUtils::GetGlobalRandom` (PCG32) must stay deterministic for lockstep and replay; roll secrecy is an authoritative-server design. [Details](notes-core-and-threading-details.md#13-the-gameplay-rng-is-deliberately-not-cryptographic)
16. **Read environment variables only through `Core/Environment.h`:** `IsTruthy` (toggle), `IsExactly` (a typo must not read as on), `GetInt`, `Get`. No private wrappers, read once at startup, and log `*value` since `Env::Get` returns `std::optional<std::string>` that fmt cannot format. [Details](notes-core-and-threading-details.md#14-environment-variables-one-reader-and-dont-add-a-modal-escape-hatch)
17. **Add a one-run debug lever to `Core/DebugLevers.inl` and nowhere else.** Shapes: `TOGGLE` lenient, `EXACT` only `"1"`, `TRISTATE`, `INT`/`NUMBER` return `optional`, `TEXT` no setter. A setter marks the lever overridden before seeding. `DebugLeversTest` fails on a new `Env::` read of an `OLO_*` variable in `OloEngine/src`. [Details](notes-core-and-threading-details.md#debug-levers-go-in-the-registry-not-in-a-fresh-envistruthy)
18. **Never mark a namespace-scope `std::vector` `constinit`.** Debug STL (`_ITERATOR_DEBUG_LEVEL != 0`) rejects it, and no CI configuration builds that. Use a leaked function-local (`static auto* p = new T(); return *p;`), e.g. `Levers::SeedWarnings()`. The four lever globals keep `constinit`. [Details](notes-core-and-threading-details.md#constinit-on-a-stdvector-does-not-compile-against-msvcs-debug-stl)
19. **Write a cvar change callback as "apply the current value", read the typed accessor, and expect it at the next frame top.** `CVars::DispatchPendingChanges()` runs on the game thread; writes coalesce; `AddChangeCallback` fires once at registration; a screenshot right after a write shows the old value. Destroy pooled GPU objects via `RenderGraph::RequestTransientPoolClear()`, not in the callback. [Details](notes-core-and-threading-details.md#the-console-variable-layer-above-it-corecvarh-issue-821)
20. **A cvar type must render distinct values distinctly.** Change detection compares rendered strings; floats use shortest-round-trip `std::format("{}", v)`, and `Levers::Snapshot()` must use the same helper. [Details](notes-core-and-threading-details.md#the-console-variable-layer-above-it-corecvarh-issue-821)
21. **Use a command-line flag, not an env var, for a knob the process owns.** Env is for the OS, launchers, and one-run debug levers. Test options are `--olo-*` flags (`OloEngine/tests/TestOptions.{h,cpp}`); unknown ones are fatal; `--olo-help` lists them. Give env-seeded latches a setter (`Renderer/RenderGraphDiagnostics.h`) instead of `_putenv_s`/`setenv`. [Details](notes-core-and-threading-details.md#an-environment-variable-is-the-wrong-mechanism-for-a-knob-you-own)
22. **Ask `IsNonInteractive()` (`Core/Interactivity.h`) before any new modal, and take the least destructive answer.** A modal in an unwatched process is a hang (flat CPU, `USER32!MessageBoxA` under `cdb -p <pid> -c "~0 kn 24; qd"`). Automated hosts call `SetNonInteractive(true)`. [Details](notes-core-and-threading-details.md#do-not-add-a-fourth-way-to-skip-a-modal)
23. **Narrow the documented contract instead of describing a race, and make tests contend the claimed guarantee.** C++ has no benign race; `GPUHashMap` supports concurrent distinct keys only, tested with keys sharing one start slot. Budget a CI round for TSan: grep `WARNING: ThreadSanitizer` in the job logs. [Details](notes-core-and-threading-details.md#15-a-benign-data-race-you-documented-is-still-a-failed-tsan-job)
24. **Keep `ENTT_USE_ATOMIC` a PUBLIC definition on `OloEngine`, and add every component a `Parallelizable()` system touches to the `Scene::Scene()` pre-warm list.** A worker first-touching a view or group writes the pool map and can corrupt type ids (entt `"Unexpected type"`). [Details](notes-core-and-threading-details.md#16-entt-first-touch-from-a-worker-thread-is-a-write)
25. **Hand readers the absolute `Log::GetLogFileName()`; never reopen the log by a relative name.** The test suite changes cwd to `OloEditor/` (#1572). [Details](notes-core-and-threading-details.md#17-the-log-file-name-is-absolute-because-the-test-suite-changes-directory)
