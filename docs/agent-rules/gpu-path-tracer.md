# The GPU reference path tracer — what it is for, and the rules that keep it an oracle

Issue #1055 (#979 Phase 2). Code: `Renderer/Passes/GpuPathTracerPass.{h,cpp}`, `Renderer/PathTracing/EmissiveTriangleTable.{h,cpp}`, `Renderer/PathTracing/GpuPathTracerTypes.h`, `OloEditor/assets/shaders/GpuPathTracer.glsl`, `include/PathTracerSampler.glsl`. Read before touching the tracer, the CPU reference it mirrors, or anything that uses its output as ground truth. It is a reference mode: off by default (`PostProcessSettings::GpuPathTracer`), Vulkan with hardware ray queries only, and the raster graph still runs underneath (skipping it is #1346).

## Rules

1. **Change `PathTracer.cpp` transport, sampler dimension order or light model and `GpuPathTracer.glsl` in the same commit.** Both tracers must draw the same random numbers per (pixel, sample, dimension) in the same order: pixel jitter, then per bounce emissive NEE select + point, BSDF lobe + shape, Russian-roulette draw. `PathTracerSamplerParityTest` pins the sampler bitwise; `GpuPathTracerDeviceParityTest` pins the Cornell box (2% on region means, 1% on frame mean at 64 spp). A budget that must widen is a bug in one tracer; do not raise the tolerance. [Details](gpu-path-tracer-details.md#1-it-mirrors-the-cpu-tracer-term-by-term-or-it-is-not-a-reference)
2. **Keep the light density one global constant.** Emissive triangles are selected uniformly by area, pdf `1 / total area`. `EmissiveTriangleTable` is built on the CPU from the same mesh sources in extraction order; `GpuPathTracerContractTest` checks it against `ReferenceScene::GetEmissiveTriangles()`. [Details](gpu-path-tracer-details.md#1-it-mirrors-the-cpu-tracer-term-by-term-or-it-is-not-a-reference)
3. **Shade every hit with its own closure.** `PtEvaluateBRDF` / `PtBsdfPdf` / `PtSampleBRDF` dispatch on the material's `ClosureVersion` as `PBRClosureBSDF.h` does; each closure has its own Cornell parity test. [Details](gpu-path-tracer-details.md#1-it-mirrors-the-cpu-tracer-term-by-term-or-it-is-not-a-reference)
4. **Use one texture convention on both tracers.** Level 0, bilinear, REPEAT; colour maps (albedo, emissive) sRGB-decoded, data maps (metallic-roughness, normal) linear; metallic = blue, roughness = green; normal map in the triangle's analytic UV tangent frame (`ReferenceScene::ApplyNormalMap` and `PtApplyNormalMap` are one formula). Emissive records carry UVs and the map. Where the descriptor heap cannot be indexed ([vulkan-shader-heap-indexing.md](vulkan-shader-heap-indexing.md)), hits shade from factors and masked geometry traces as solid, both counted. [Details](gpu-path-tracer-details.md#1-it-mirrors-the-cpu-tracer-term-by-term-or-it-is-not-a-reference)
5. **Detect camera change bitwise on the UNJITTERED view and projection.** `RenderPipeline` hands the pass `TemporalProjectionMatrix`; the jittered `ProjectionMatrix` restarts every frame with TAA on and reads as "never converges". [Details](gpu-path-tracer-details.md#2-accumulation-goes-through-the-temporal-history-registry-and-restarts-on-any-camera-change)
6. **Hash the registry tokens into the graph fingerprint.** The four RGBA32F planes are `TemporalHistoryEffect::PathTracer` entries; each invalidation bumps a generation, which makes the cached `Setup` drop its history handles. Without it a restarted accumulation keeps adding to forgotten sums. [Details](gpu-path-tracer-details.md#2-accumulation-goes-through-the-temporal-history-registry-and-restarts-on-any-camera-change)
7. **Route scene mutation through the dirty GPU Scene range.** `RecordTable::Commit` marks a slot dirty only when bytes changed; `Renderer3D::EndScene` then calls an unscoped `InvalidateTemporalHistories(SceneMutated)`, mapped to the `TemporalHistoryDependency::SceneContent` bit that only the path tracer's planes declare. The planes do not declare `Jitter`: a TAA or FSR2 toggle must not discard the sum. [Details](gpu-path-tracer-details.md#2-accumulation-goes-through-the-temporal-history-registry-and-restarts-on-any-camera-change)
8. **Expect an animated scene to restart every frame.** `ConsecutiveRestarts` counts it, the panel shows it, the log warns once after eight in a row. [Details](gpu-path-tracer-details.md#2-accumulation-goes-through-the-temporal-history-registry-and-restarts-on-any-camera-change)
9. **The sample index is the accumulated count,** so N frames at 1 spp equal one frame at N spp (`GpuPathTracerDeviceParityTest.AccumulationOverFramesDrawsTheSameSequenceAsOneFrame`). [Details](gpu-path-tracer-details.md#2-accumulation-goes-through-the-temporal-history-registry-and-restarts-on-any-camera-change)
10. **Keep the fallback structural.** `PathTracerColor` is declared only when the pass is enabled and its shader loaded (created only where `RenderCommand::SupportsRayTracing()`), so elsewhere the frame is byte-identical (`GpuPathTracerFallbackTest`). A stood-down pass uploads a ZERO TLAS address, passes the input colour through and carries the four history planes forward unchanged; only the registry restarts the sum, never the shader. [Details](gpu-path-tracer-details.md#3-the-fallback-is-structural-the-reason-is-counted)
11. **Resolve `GpuPathTracerFallbackReason` most-fundamental-first, once per change, in `ResolveAvailabilityForFrame`** (`RenderPipeline::ConfigurePassesForFrame`, after the GPU Scene commit). `Execute` adds only "no target". Do not miss `EmissiveTableNotGathered` and `PunctualLightsBeyondShaderBound` (slot past `OLO_PT_MAX_LIGHTS`, counted). [Details](gpu-path-tracer-details.md#3-the-fallback-is-structural-the-reason-is-counted)
12. **A committed hit with an out-of-range or inactive GPU Scene record is a hit on a black opaque surface, not a miss,** or the path gets environment radiance through an occluder. [Details](gpu-path-tracer-details.md#3-the-fallback-is-structural-the-reason-is-counted)
13. **Never name a GLSL parameter `sampler` or a local `sample`.** Both are reserved; the error is at the declaration. Use `pathSampler` and `result`. [Details](gpu-path-tracer-details.md#4-things-that-bit-while-building-it)
14. **Create a by-address-only `StorageBuffer` with `StorageBuffer::kNoBinding`.** A `StorageBuffer` publishes itself at its binding on construction; do not park it on another table's slot or an arbitrary out-of-range number (`VulkanBindingState` warns). [Details](gpu-path-tracer-details.md#4-things-that-bit-while-building-it)
15. **Never `SetData` into a by-address buffer a submitted frame may still read.** Publish a fresh buffer when bytes change and drop the old `Ref`; deferred reclaim keeps the old allocation alive. The pass resolves the address every frame. [Details](gpu-path-tracer-details.md#4-things-that-bit-while-building-it)
16. **Row 0 is the top on Vulkan off-screen targets, bottom on GL.** The shader derives pixel seed and primary ray under `#ifdef OLO_VULKAN` from the CPU film's convention; the primary ray uses `inverse(P * V)` in GL clip convention, not `RHIProjectionSeam`'s inverse. [Details](gpu-path-tracer-details.md#4-things-that-bit-while-building-it)
17. **Include paths differ for probes.** A `.glsl` probe in `assets/shaders/tests/` includes `include/...` relative to the shader root, so glslc validation of a probe needs `-I <root>`; a production shader (`../include/...`) must not pass one. [Details](gpu-path-tracer-details.md#4-things-that-bit-while-building-it)
18. **Mirror `PathTracer.cpp`'s `ViewSphereLight` for sphere-area lights** (solid-angle sampling with MIS, visible to camera and bounce rays, non-occluding). Out of scope on purpose: RT pipeline/SBT, denoiser, mip selection. [Details](gpu-path-tracer-details.md#5-running-it)
