# Subsystem notes — editor panels, asset pipeline, platform utils

Gotchas for the Content Browser, `EditorAssetManager`, asset serializers, the texture cook, graph panels and the cross-platform file dialogs. Read before touching any of them.

## Rules

1. **Resolve no dependent asset inside `AssetImporter::TryLoadData`.** The serializer registry `FMutex` is non-recursive; a serializer that calls `AssetManager::GetAsset` froze the whole editor with no log (#646, now narrowed to the lookup). Take what you need from the caller (`Tileset::GetTileUVForAtlas`); a cycle is now infinite recursion. For a silent hang attach `cdb` and dump the main thread. [Details](notes-editor-and-assets-details.md#an-asset-serializer-that-resolves-a-second-asset-deadlocks-the-whole-editor-silently)
2. **Cover both serializers when two serialize one type.** `MaterialAssetSerializer` loaded typed maps into the generic uniform map via `Material::Set`; use the name-to-setter table (`SetAlbedoMap` and friends) and test the serializer you did not write. [Details](notes-editor-and-assets-details.md#materialasset-yaml-wrote-the-typed-pbr-maps-and-loaded-them-into-the-generic-uniform-map)
3. **Initialize absent relationships with `UUID(0)` or `{ 0 }`.** `UUID{}` generates a new identity. Test the stored UUID and whether it resolves. [Details](notes-editor-and-assets-details.md#use-an-explicit-zero-uuid-for-absent-relationships)
4. **Call `DirectoryTree::MarkDirty(<asset-root-relative dir>)` to surface a file live.** The Content Browser reads the filesystem, not the registry. Convert with `std::filesystem::relative(absPath.parent_path(), assetRoot)` (assetRoot is `Project::GetAssetDirectory()`, not the project dir) and reject a leading `..`. [Details](notes-editor-and-assets-details.md#1-the-content-browser-reads-the-filesystem-not-the-asset-registry)
5. **Treat `OnFileSystemEvent` presence as `{added, modified, renamed_new}` and drops as `{removed, renamed_old}`.** It runs on the game thread; `ImportAsset` is idempotent and metadata-only. Hot-reload only assets with `IsAssetLoaded` (`DecideFileWatchAction` in `Asset/AssetFileWatchPolicy.h`). `AssetRegistry.oar` is git-tracked: revert it after live drop-file tests. [Details](notes-editor-and-assets-details.md#2-the-filewatch-auto-import-seam)
6. **Before calling a reload path unreachable, confirm something resolved the asset.** Check `olo_virtual_geometry_stats` (`renderingPath`, `note`) and look for a `Loaded asset: <path>` trace; virtual-mesh sources resolve only on the Deferred path. [Details](notes-editor-and-assets-details.md#2-the-filewatch-auto-import-seam)
7. **Substitute missing-asset placeholders at `AssetManager::GetAsset<T>()`.** Managers substitute when they know the type; the facade substitutes by `T::GetStaticType()` for dangling handles and unwraps with `UnwrapPlaceholder`. Warn once per handle. Keep `GetStaticType()` public; bind `Ref<Asset>` before `.As<T>()` (Clang needs `.template`), and run `cmake --preset clangcl` before pushing template header changes. [Details](notes-editor-and-assets-details.md#3-missing-asset-placeholders-intercept-at-the-typed-facade)
8. **Grep before naming a new top-level `OloEngine::Xxx`; use the `XxxAsset` suffix for asset classes.** `Scene/Components.h` drags in most TUs, so a clash shows far away. Enum, extension, YAML key and serializer keep the plain name. [Details](notes-editor-and-assets-details.md#4-grep-before-naming-a-new-top-level-oloenginexxx)
9. **Hold runtime-only per-`Scene` state as a `std::unique_ptr<T> m_X` on `Scene`, not a component.** Forward-declare in `Scene.h`, out-of-line accessors plus const overload, init in declaration order in the ctor, `m_X->Clear()` in `OnRuntimeStop` (mirror `GameplayEventBus` / `UINavigation`). A helper reading private members must be a member of the friend class. [Details](notes-editor-and-assets-details.md#5-runtime-only-per-scene-state--dont-reach-for-a-component)
10. **Call `bc7enc_compress_block_params_init(&p)` first, then the linear-weights init.** The partial initializers leave other fields uninitialized. Call `bc7enc_compress_block_init()` and `rgbcx::init()` once (`std::call_once`); compile only `bc7enc.cpp`, `bc7decomp.cpp`, `rgbcx.cpp`. [Details](notes-editor-and-assets-details.md#6-bc7enc_rdo-the-partial-params-initializers-encode-from-garbage)
11. **Keep `EncodeBC6HBlockUnsigned` (mode 11, unsigned) validated against vendored `bcdec`.** The `aWeight4` table is asymmetric (index 13 is 55), so re-select indices after an anchor swap. Do not auto-select BC5 for normals. Cook failure falls back to the raw record. [Details](notes-editor-and-assets-details.md#7-bc6h-is-a-hand-written-mode-11-encoder-validated-against-an-independent-decoder)
12. **Bump `kCinematicSequenceVersion` for provenance only, and emit per-key fields unconditionally.** The `.olocine` reader defaults every field; a Bezier segment needs the right key's `InTangent` (`CinematicSerializerTest.BezierTangentsRoundTrip`). [Details](notes-editor-and-assets-details.md#8-olocine-versioning-tolerant-reader-version-for-provenance-only)
13. **Use `FileDialogs::ShowInFileManager(path)` to reveal a path.** No new Windows-only `ShellExecuteW`; include `<shellapi.h>` explicitly. Linux dialogs use `zenity`/`kdialog`; the `filter` argument stays the Win32 double-NUL format on both platforms. Leave ELF icon embedding and crash-reporter register dump non-parity alone. [Details](notes-editor-and-assets-details.md#9-platform-utils)
14. **Treat `Video/PlMpeg.cpp` as vendored.** Its `#include <stdio.h>` is required (SonarQube `cpp:S988` is a false positive); `Video/PlMpegBackend.cpp` is first-party. [Details](notes-editor-and-assets-details.md#10-videoplmpegcpp-is-vendored-not-first-party)
15. **Split a model file to animate parts independently, and re-origin the part.** Use `scripts/split-glb-nodes.py`; drop the extracted node's `translation` so its pivot is the file origin. Register new `.glb` files in `AssetRegistry.oar` (`AssetContentValidity.EverySupportedAssetOnDiskIsInTheRegistry`) and check the model's forward axis before trusting rotation signs. [Details](notes-editor-and-assets-details.md#splitting-one-model-into-several-entities-issue-899)
16. **Keep the `OloEditor` to `OloEngine-ScriptCore` / `Sandbox-Scripting` dependency edge in root `CMakeLists.txt`,** inside `if(OLO_WITH_CSHARP)` next to the `OloRuntime` edge. The symptom is `[ScriptEngine] OloEngine-ScriptCore assembly unavailable`; also check `OLO_WITH_CSHARP=ON`. [Details](notes-editor-and-assets-details.md#a-targeted---target-oloeditor-build-ships-without-c-scripting-if-one-dependency-edge-goes)
17. **Grep `AssetExtensions.cpp` `s_ExtensionMap` before adding an importer for an extension.** `.ply` is already `MeshSource`; a Gaussian-splat PLY fails in assimp as a broken mesh. Coexisting formats must be discriminated by file content, not extension. Verify importer behaviour by running it before writing the claim. [Details](notes-editor-and-assets-details.md#ply-is-already-claimed-by-the-mesh-importer-so-a-gaussian-splat-ply-fails-as-a-broken-mesh)
18. **Never DPI-scale the MCP viewport override.** `olo_viewport_set_size` writes pixels into `m_ViewportSize`; skip the display-scale multiply while an override is active. Test with an override larger than the window, and never delete the post-chain assertions to "fix" it. [Details](notes-editor-and-assets-details.md#the-mcp-viewport-override-is-in-pixels-so-it-must-not-be-dpi-scaled-again)
19. **Use `EditorUI::GraphCanvas` only for panels that have a canvas.** `AnimationGraphEditorPanel`, `FSMEditorPanel`, `BehaviorTreeEditorPanel` do not; judge by what a panel draws, not line count. The decisive census grep is `grep -rln "AddBezierCubic" OloEditor/src/` (only `GraphCanvas.cpp` should hit); `AnimationPanel`'s `m_TimelineZoom` is a known false positive. [Details](notes-editor-and-assets-details.md#three-of-the-graph-panels-are-not-canvases--rank-by-what-a-panel-draws-not-by-line-count)
20. **In graph panels, floor hit radii in screen pixels, capture `ToGraph(mousePos)` at click time, and fit with `FitToBounds`.** Use `std::max(s_PinHitRadiusMin, m_Canvas.Scaled(r))`, `GetOrigin()`/`GetSize()`; the widget owns right-drag pan, cursor-anchored zoom over [0.15, 3.0], and right-release menus. [Details](notes-editor-and-assets-details.md#what-the-three-migrations-actually-cost-and-what-they-fixed)
