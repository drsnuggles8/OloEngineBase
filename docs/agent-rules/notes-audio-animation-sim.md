# Subsystem notes — audio/SoundGraph, animation, and the fixed-timestep sim loop

Gotchas from SoundGraph parameter routing and spatialization, animation pose sampling and retargeting, morph targets, the deterministic tick, scene authoring and frame pacing. Reference notes, not failure postmortems; read the matching rule before touching that subsystem.

## Rules

1. **Map animation channels to bones by name, never by index.** `clip.BoneAnimations[i]` is not skeleton bone `i` on a real rig. Use `clip->FindBoneAnimation(boneName)`; bones a clip does not key fall back to the bind-pose local transform (`m_BindPoseLocalTransforms`, TRS form), never identity. [Details](notes-audio-animation-sim-details.md#1-map-animation-channels-to-bones-by-name-never-by-index)
2. **Build the whole `PoseEvalContext` in any new pose-sampling path.** It has five index-aligned spans (`Animation/BlendNode.h`): `BoneNames`, `BindPose`, `ParentIndices`, `BindPoseGlobals`, `PreTransforms`. [Details](notes-audio-animation-sim-details.md#1-map-animation-channels-to-bones-by-name-never-by-index)
3. **Retarget rotation as a delta re-base.** `R_target = R_target_rest · (R_source_rest⁻¹ · R_source_anim)`, then `glm::normalize`; a plain copy works only for identical rest orientations. [Details](notes-audio-animation-sim-details.md#2-retargeting-re-base-the-rotation-dont-copy-it)
4. **Emit at least one constant key per channel for every mapped bone in a baked clip.** An empty keyframe channel samples to defaults (`vec3(0)`, scale `vec3(1)`, identity rotation) and collapses the bone. Reuse `BoneTransform`. [Details](notes-audio-animation-sim-details.md#2-retargeting-re-base-the-rotation-dont-copy-it)
5. **Call `SetBindPose()` on any skeleton built in a test.** `m_BindPoseLocalTransforms` / `m_BindPoseMatrices` are populated only by it. [Details](notes-audio-animation-sim-details.md#2-retargeting-re-base-the-rotation-dont-copy-it)
6. **Clamp writes into a caller-sized `std::span` to `std::min(expected, span.size())`.** An `OLO_CORE_ASSERT` gives no release-build protection. [Details](notes-audio-animation-sim-details.md#2-retargeting-re-base-the-rotation-dont-copy-it)
7. **Sample graph-path morph clips at `GetCurrentStateNormalizedTime() * Clip->Duration`.** Raw `m_CurrentStateTime` is speed-scaled. Keep the global morph block after the animation-graph update (one-frame lag otherwise). [Details](notes-audio-animation-sim-details.md#3-morph-targets-feed-one-global-loop-from-two-animation-paths)
8. **Test morph evaluation by sampling plus a direct `MorphTargetSystem::EvaluateMorphTargets` call.** The eval loop needs a GL context (`vb->SetData`). `CollectActiveMorphClips` handles only SingleClip states; `EvaluateMorphEvaluator::EvaluateGPU` is still a stub. [Details](notes-audio-animation-sim-details.md#3-morph-targets-feed-one-global-loop-from-two-animation-paths)
9. **Never put a fixed-timestep accumulator in `Scene::OnUpdateRuntime`.** It must advance the sim by exactly `ts` (about 100 Functional tests, `OloServer` and `RendererAttachedTest` depend on it). The accumulator lives in `Scene::OnUpdateRuntimeFixed(frameTs, fixedDt)`, used only by windowed hosts (editor Play, `OloRuntime`). [Details](notes-audio-animation-sim-details.md#4-the-fixed-timestep-accumulator-must-not-live-in-onupdateruntime)
10. **Route both entries through `SimulateRuntimeStep`.** `OnUpdateRuntimeFixed` runs it N times (clamped at `s_MaxFixedStepsPerFrame = 15`) and `RenderRuntime` once; `fixedDt = 1/60` matches `JoltScene::m_FixedTimeStep`. The step bumps `m_SimulationTick`. [Details](notes-audio-animation-sim-details.md#4-the-fixed-timestep-accumulator-must-not-live-in-onupdateruntime)
11. **Render interpolation overwrites the live local transform, renders, then restores a full `TransformComponent` copy (`*tc = savedCopy`).** Restoring via `SetRotation()` drifts `RotationEuler`. Exclude the primary camera from the geometry overwrite (blend a gameplay camera into `cameraTransform`). Interpolation must never touch persisted sim state. [Details](notes-audio-animation-sim-details.md#5-render-interpolation-overwrites-and-restores-the-live-transform)
12. **Key interpolation snapshot maps by `u32`, use `view.size()` for single-component views, and do not name helper structs `*Component`.** [Details](notes-audio-animation-sim-details.md#5-render-interpolation-overwrites-and-restores-the-live-transform)
13. **Do not assume a SoundGraph exposes `Volume`/`Pitch`/`Loop`/`LowPass`/`HighPass`.** `SoundGraphSound` routes `Set*` best-effort; a missing endpoint is a silent no-op. The handle is `static_cast<u32>(Identifier{endpointName})` (FNV hash); the accessor is `GetParameters()`, not `GetParameterEndpoints()`. [Details](notes-audio-animation-sim-details.md#6-soundgraph-parameter-routing-is-opt-in-per-graph)
14. **Register preset descriptors with `ID = static_cast<u32>(Identifier{endpointName})`.** `SoundGraphPatchPreset` well-known IDs (Volume=1, Pitch=2, LPF=10, HPF=11) are arbitrary ints and will not resolve against a real graph. [Details](notes-audio-animation-sim-details.md#6-soundgraph-parameter-routing-is-opt-in-per-graph)
15. **Test `SoundGraphSource` device-free.** Never call `Initialize(engine, ...)`; use `ReplaceGraph` + `ProcessSamples`, and `SoundGraphSound::InitializeDetachedSource()` for the wrapper. [Details](notes-audio-animation-sim-details.md#6-soundgraph-parameter-routing-is-opt-in-per-graph)
16. **Hand parameters to the audio thread through the SPSC queue, never a mutex or allocation.** `Audio::LockFreeEventQueue<T, 256>` carries `{ u32 m_ParameterID; Audio::PreAllocatedValue m_Value; }`: main thread `CopyFrom` + `Push()`, audio thread `Pop()` in `ProcessSamples` and `SendInputValue`. Single live `SetParameter` writes go straight to `SendInputValue`; only bulk preset apply is queued. [Details](notes-audio-animation-sim-details.md#7-mainaudio-thread-handoff-is-an-spsc-queue-not-a-mutex)
17. **`Clear()` the queue in `ReplaceGraph` after the swap, and treat a queue-full drop of a resolvable parameter as failure.** Otherwise a value validated against the old graph lands on a same-hash endpoint of the new one. [Details](notes-audio-animation-sim-details.md#7-mainaudio-thread-handoff-is-an-spsc-queue-not-a-mutex)
18. **Null-guard the bare-node case in Spatializer code.** `Audio::DSP::Spatializer` has `InitSource` overloads for `ma_engine_node*` (Doppler works) and `ma_node_base*` (bare node, Doppler skipped). `ma_engine_node` has `.resampler`/`.spatializer`/`.baseNode`; `ma_node_base` does not. SoundGraph spatialization is a runtime-only flag, not serialized. [Details](notes-audio-animation-sim-details.md#8-the-spatializer-hosts-two-upstream-flavours)
19. **Free all three `InitSource` allocations in `ReleaseSource`.** The `ma_node`, the `Scope<VBAPData>` and the `ma_channel_converter`; mirror every `ma_*_init` with `_uninit`. [Details](notes-audio-animation-sim-details.md#8-the-spatializer-hosts-two-upstream-flavours)
20. **Test the spatializer with a device-free `ma_engine`.** `config.noDevice = MA_TRUE` plus channels/sampleRate/listenerCount; `FunctionalTest::EnableAudio` does not call `AudioEngine::Init`. [Details](notes-audio-animation-sim-details.md#8-the-spatializer-hosts-two-upstream-flavours)
21. **Keep `SoundGraphCache` in-memory; put cross-run persistence in `CompilerCache`.** Do not re-add YAML persistence to the cache. `Ref<SoundGraph>` is never serialized; only bytecode is. New buffer-owning node types override `NodeProcessor::GetHeapBytes()` (as `WavePlayer` does). [Details](notes-audio-animation-sim-details.md#9-two-soundgraph-caches-with-distinct-roles)
22. **Author box collider `HalfExtents` in mesh-local units.** A unit cube scaled `[160,1,160]` needs `[0.5,0.5,0.5]`, or `ValidateBoxDimensions` fails and the engine silently substitutes a default shape. [Details](notes-audio-animation-sim-details.md#10-authoring-olo-scenes-programmatically)
23. **Run scenes that need physics, scripts, animation or world-space `SpriteRendererComponent`s in Play mode.** Edit mode renders the editor camera (pose via `olo_camera_set_pose`) and ticks none of them. [Details](notes-audio-animation-sim-details.md#10-authoring-olo-scenes-programmatically)
24. **Write `AnimationStateComponent::SourceFilePath` as a content path (#1539).** `assets/models/Fox/Fox.gltf` for engine content, `Assets/...` for project content, resolved by `ResolveContentPath`. [Details](notes-audio-animation-sim-details.md#10-authoring-olo-scenes-programmatically)
25. **Verify a swarm workload actually runs, and commit a scene that references generator-only scripts.** Probe a designated entity's Translation twice. A `.cs`/`.lua` referenced only by git-ignored generated scenes fails the "every script is referenced by a scene" CI tests; a `.cs` also needs an `AssetRegistry.oar` entry. [Details](notes-audio-animation-sim-details.md#10-authoring-olo-scenes-programmatically)
26. **Respect engine limits.** Jolt MaxBodies 65536, MaxBodyPairs 65536, MaxContactConstraints 10240 (overflow gives `Jolt physics update error: 4`); per frame 4096 bone matrices, 16384 instance colors/entityIDs, 1024 unique materials. Overflow errors are unthrottled and can stall the editor. [Details](notes-audio-animation-sim-details.md#10-authoring-olo-scenes-programmatically)
27. **Pair `timeBeginPeriod(1)`/`timeEndPeriod(1)` with any frame cap on Windows.** `Core/FramePacer.{h,cpp}` does it while a cap is active, called after `SwapBuffers`. Sleep-based pacing uses a coarse `sleep(remaining - margin)` plus a ~1 ms busy-spin, and the spin must be guarded by `Time::HasMockTime()` or deterministic captures hang. [Details](notes-audio-animation-sim-details.md#11-frame-pacing-needs-1-ms-timer-resolution-on-windows)
